# 사인검 로그라이트 전환 기획

작성일: 2026-10-07

상태: 사용자와 합의된 방향을 기록한 기획 초안. 미정 항목은 후속 논의에서 결정합니다.

## 전환 목적과 범위

사인검을 **오행 5폼과 상성을 활용하며 영구 성장이 있는 3D 스타일리시 액션 로그라이트**로 전환합니다. 사용자 논의에서 사용한 장르 표현은 로그라이크이며, 이 문서에서는 이후 확정한 허브 영구 성장 구조를 분명하게 표현하기 위해 로그라이트로 표기합니다.

고정 스토리 스테이지와 자매 부양·호감도 성장 순환을 제거합니다. 허브에서 누적 강화한 뒤 던전에 입장하고, 무작위 전투 구역을 이어가며 강화 선택과 아이템 보유 시너지로 매 런의 조합을 구성합니다. 사망하면 실적에 따라 특수 재화를 얻어 허브의 영구 강화에 사용합니다.

이 문서는 이번 논의에서 확정한 기획 결정과 기존 문서의 영향 범위를 기록합니다. 승인된 초기 수치는 포함하지만, 코드 구현과 전체 밸런스까지 확정한 명세는 아닙니다.

Enter the Gungeon은 무작위 전투 구역을 이어가는 진행 방식의 참고입니다. 총기 전투, 시점, 층수 등 게임 전체 시스템을 복제한다는 뜻은 아닙니다. 층 보스와 매 층 상점은 사용자가 별도로 확정한 요소입니다.

## 핵심 순환과 성장의 구분

1. 허브에서 특수 재화를 사용해 영구 강화하고 던전에 입장합니다.
2. 무작위 전투 구역에서 적을 처치해 돈을 획득합니다. 런 내 강화 선택과 아이템 보유 시너지로 조합을 구성하고, 각 층의 상점에서 돈으로 아이템을 구매할 수 있습니다.
3. 해당 층 보스를 격파하면 돈·아이템·허브 강화용 특수 재화 중 하나를 선택합니다. 보스 격파는 다음 층 진입 조건입니다.
4. 사망 시 실적을 정산하고 런의 돈·아이템·선택 강화를 초기화합니다. 최종 클리어 시 같은 실적 정산에 특수 재화 30개를 추가합니다. 메뉴에서 포기하면 실적 정산 없이 런의 돈·아이템·선택 강화를 초기화하고 허브로 돌아갑니다.
5. 유지된 특수 재화와 영구 강화를 바탕으로 허브에서 다음 도전을 준비합니다.

강화 선택은 일반 전투 구역의 적 전멸 시 1회 지급합니다. 보스 구역에서는 아래의 보스 선택 보상으로 대체합니다. 상점은 보스방 직전의 안전 구역에 배치합니다. 최종 5층 보스 격파 후 보상을 선택하고 허브로 귀환합니다. 최종 클리어 시 실적 정산과 특수 재화 30개 보너스를 지급합니다. 클리어 후 런 자원의 처리 규칙은 미정입니다.

| 구분 | 획득 또는 형성 | 용도 | 사망 후 처리 |
| --- | --- | --- | --- |
| 런의 돈 | 허브 시작 골드 강화분·일반 적 처치·아이템 판매·보스 보상에서 돈 선택 | 해당 런의 층별 상점에서 아이템 구매·유료 새로고침·회복 서비스 | 초기화 |
| 런의 아이템·선택 강화 | 아이템 구매·구역 선택 보상·합성·보스 보상에서 아이템 선택 및 일반 전투 구역 전멸 보상으로 지급하는 강화 선택. 그 밖의 아이템 획득처는 미정 | 해당 런의 전투 조합과 보유 시너지 | 초기화 |

런의 돈과 특수 재화는 획득처·사용처·유지 규칙이 다른 두 재화입니다. 기존 영핵·영약·선물·호감도 순환을 이 구조에 그대로 옮기지 않습니다.

## 런의 돈 수급

2026-10-07 사용자 승인으로 다음 초기 수치를 적용합니다.

- 기본 시작 골드는 0입니다. 던전 입장 시 허브의 시작 골드 강화분을 더합니다.
- 일반 적 한 마리의 처치 수입은 **현재 층 + 4골드**입니다. 1~5층에서 각각 5·6·7·8·9골드이며 바닥 드롭 없이 즉시 지급합니다.
- 보스 보상에서 돈을 선택하면 **현재 층 × 50골드**, 특수 재화를 선택하면 **현재 층 × 10개**를 받습니다.
- 보스 처치 자체로 별도 골드를 지급하지 않습니다. 보스 보상은 기존처럼 돈·아이템·특수 재화 중 하나만 선택합니다.

## 상점 상세 규칙 1차 승인

아래 세 항목은 2026-10-07 사용자 승인으로 확정했습니다. 상점에서 사용하는 재화는 해당 런의 돈입니다.

### 1 상점 열기와 닫기

- 플레이어가 상인과 상호작용할 수 있는 가까운 범위에 있으면 `E: 상점 이용` 안내를 표시합니다.
- 해당 범위에서 E키를 누르면 상점 UI를 엽니다.
- 상점 UI가 열린 상태에서 Esc키를 누르면 UI를 닫습니다.
- 상호작용 가능 거리의 정확한 값은 미정입니다.

### 2 안전 구역과 일시정지

- 상점은 매 층 보스방 직전의 적이 없는 별도 안전 구역에 배치합니다.
- 상점 UI가 열려 있는 동안 게임을 일시정지합니다. 이 동안에도 상점 UI의 아이템 선택·구매·닫기 입력은 처리합니다.
- 상점 UI를 닫으면 상점 이용에 따른 일시정지를 해제합니다.
- 보스방 직전이라는 배치 조건 외에 안전 구역의 세부 구조는 미정입니다.

### 3 상품 확인과 구매

- 상점의 아이템 판매 목록은 5칸으로 구성합니다. 선택한 오행의 미보유 후보가 5개 미만이면 가능한 만큼만 진열합니다.
- 플레이어가 아이템을 선택하면 선택한 아이템의 설명·가격과 현재 보유 금액을 표시합니다.
- 구매 버튼을 누르면 선택한 아이템을 즉시 구매합니다. 구매 성공 시 표시 가격만큼 런의 돈을 차감하고 선택한 아이템의 획득을 처리하며 보유 금액 표시를 갱신합니다.
- 보유 금액이 선택한 아이템의 가격보다 적으면 구매 버튼을 비활성화합니다.
- 보유 금액이 가격 이상이면 금액 조건을 충족합니다. 이미 보유한 아이템은 아래 아이템 기본 규칙에 따라 이후 상점 후보에서 제외합니다.

- 서로 다른 아이템의 보유 개수에는 제한을 두지 않습니다.

### 3 동일 아이템의 중복 방지

- 한 런에서 동일한 고유 ID의 아이템은 최대 1개만 보유할 수 있습니다.
- 이미 보유한 아이템은 이후 상점 판매 후보와 보상 후보에서 제외합니다.
- 후보를 구성할 때 현재 런의 보유 아이템 ID를 기준으로 제외 여부를 판단합니다.
- 이 규칙은 서로 다른 아이템을 함께 보유해 시너지를 만드는 방식과 함께 적용합니다.

### 2 합성 재료와 확인
