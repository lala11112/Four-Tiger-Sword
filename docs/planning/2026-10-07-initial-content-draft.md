# 사인검 초기 콘텐츠 명세 초안

작성일: 2026-10-07

**상태: 제안·검토 대기.** 이 문서는 사용자가 승인한 콘텐츠 규모 안에서 개별 데이터와 처리 방식을 한 번에 검토하기 위한 초안입니다. 작성·커밋·업로드 승인은 아래 개별 효과·수치에 대한 승인을 뜻하지 않습니다. 구현 착수 명세가 아니며, [확정 결정 문서](2026-10-07-roguelike-direction.md)의 규칙이 우선합니다.

## 확정 범위와 초안의 경계

| 확정된 제작 범위 | 이번 초안에서 제안하는 내용 |
| --- | --- |
| 일반 적 3종: 근접 추격·원거리 사격·돌진, 각 적에 고정 오행 부여 | 데이터 ID·행동 조건·체력·이동·공격 수치 |
| 보스 1종을 5층에 강화 재사용 | 동일 패턴 3개와 층별 능력치 배율 |
| 아이템 20개: 오행별 4개, 각 등급 1~4 하나씩 | 이름·패시브 효과·조건·수치·중첩 규칙 |
| 선택 강화 10종: 공통 5종+폼별 전용 1종 | 최대 레벨·각 레벨 값·대상과 표시 정보 |
| 보유 시너지 5조합 | 필요한 아이템 ID와 보유 효과 |

이하 **이름·ID·개별 콘텐츠 값·수식·상한·내부 처리 순서는 모두 제안·검토 대기**입니다. 반면 아래 기준값은 이미 확정된 규칙입니다.

- 아이템 가격: 1/2/3/4등급 20/40/80/160골드. 일반 구역·상점 등급 가중치 50/30/15/5, 보스 아이템 3/4등급 80/20. 빈 등급은 제외 후 남은 비율 재정규화.
- 현재 보유한 동일 ID는 다시 보유하지 않으며, 한 후보 목록 안에도 같은 아이템을 중복 제시하지 않습니다.
- 합성: 서로 다른 3등급 2개+2등급 1개를 소비하여 선택 오행의 미보유 4등급 하나를 획득. 추가 골드 없음, 후보가 없으면 재료를 소비하지 않음.
- SP 기준 최대 100, 입장 시 가득, 마지막 소비 후 1초 지연·초당 20 재생. 기본 회피 비용 20·전환 비용 10. 실패 입력은 무소모·쿨타임 미시작.
- 폼 전환 공통 쿨타임 2초. 공통 회피 거리 4.5m·시작 즉시 무적 0.2초·전체 동작 0.4초. 회피 중 재회피·폼 전환 불가.
- 성공한 다른 폼 전환은 새 폼 강화 스킬 1회 발동. 폼 전환의 SP 비용과 스킬 발동은 한 동작이며, 초안에서 스킬에 별도 SP 비용을 추가하지 않습니다.
- 오행 피해 배율은 유리 150%·역상성 75%·그 외 100%. 공격 속성은 시작 시 고정, 플레이어 피격 방어 속성은 명중 순간 현재 폼을 사용합니다.
- 아이템·선택 강화는 사망·메뉴 포기 시 초기화합니다. 최종 클리어 후 런 자원 처리는 여전히 결정 대기입니다.

## 공통 데이터와 생명주기 제안

### 필드와 소스 관리

- 아이템 데이터는 ID, 이름, `IconKey`, 설명, 등급, 가격, 고정 오행, 효과·값, 시너지 태그를 가집니다. 표의 이름·효과 설명을 표시 문구 초안으로 사용합니다.
- 강화 데이터는 ID, 이름, `IconKey`, 설명, 대상 폼, 최대 레벨, 레벨별 효과 값을 가집니다. 선택 UI는 현재→다음 레벨과 실제 적용 수치를 보여줍니다.
- `IconKey`는 `icon.<ID>` 규칙의 임시 키입니다. 아이콘 원화와 리소스는 아직 제작되지 않았습니다. 키가 존재한다고 에셋이 완성된 것은 아닙니다.
- 수치 변경마다 소스 ID를 붙입니다. 같은 아이템은 1개만 적용하며 판매·합성 소비 시 해당 소스의 상시 효과·조건부 효과·잔여 버프를 즉시 제거합니다.
- 같은 강화의 레벨 상승은 이전 레벨 값을 새 레벨 값으로 교체합니다. 레벨1+레벨2 값을 다시 더하지 않습니다.
- 시너지는 지정된 ID를 모두 보유할 때 1회 활성화하며, 서로 다른 시너지는 동시에 적용합니다. 판매·합성으로 조건이 깨지면 해당 소스 효과를 즉시 제거합니다.
- 사망·포기 시 모든 런 소스와 그 타이머를 제거합니다. 일시정지에서는 SP 재생 지연·재생량·버프 등 게임 시간 기반 진행을 멈춥니다.
- 저장에는 보유 ID·강화 레벨과 함께 조건부 버프의 소스·잔여시간·중첩을 기록하는 방식을 제안합니다. 재개 과정이 획득·전환 이벤트를 다시 발생시키지 않도록 합니다.

### SP 경제와 가산 수식

개별 효과가 기준 SP 값을 조정하도록 제안하되, 폼 전환 2초 쿨타임과 공통 회피 거리·무적·동작 시간은 이 콘텐츠 초안에서 변경하지 않습니다.

| 최종 값 | 제안 산식·제약 |
| --- | --- |
| 최대 SP | `min(200, 100 + 아이템·강화·시너지의 최대 SP 가산 합)` |
| SP 재생량/초 | `min(40, 20 + 재생 가산 합)`. 마지막 실제 SP 소비 후 1초 지연 유지 |
| 회피 SP 비용 | `max(8, 20 - 회피 비용 감소 합)` |
| 폼 전환 SP 비용 | `max(4, 10 - 전환 비용 감소 합)` |

- SP 최대치 증가만으로 현재 SP를 추가 지급하지 않습니다. 최대치 감소 시 현재 SP를 새 최대치까지만 제한합니다. 판매·재구매·합성으로 SP가 만들어지지 않게 합니다.
- 자동 재생은 최대치까지만 적용합니다. 비용은 행동 시작 시 계산한 최종 값이며, 부족 여부 확인에 같은 값을 사용합니다. 성공할 때 한 번만 차감합니다.
- 실패 입력은 SP·현재 쿨타임·재생 지연 타이머를 변경하지 않는 처리 순서를 제안합니다. 이미 진행 중인 쿨타임을 초기화하지 않습니다.
- 최대 체력 증가도 현재 체력을 즉시 회복시키지 않고, 감소할 때만 현재 체력을 상한에 맞춥니다. 허브 강화와 런 최대 체력 효과의 백분율은 기본 최대 체력을 기준으로 가산하는 방식을 제안합니다.
- 일반 공격과 전환 스킬의 피해 가산은 각각 별도 합산합니다. 최종 공격 피해는 `해당 공격의 기본 피해 × (1 + 허브 공격력 증가율) × (1 + 해당 공격 종류·폼에 적용되는 피해 가산 합) × 오행 배율`로 제안합니다. 폼별 기본 피해·타격 수는 별도 결정 대기입니다.
- 공격 수치는 시작 시 스냅샷으로 고정하고, 피격 측 조건은 명중 시 평가하는 방식을 제안합니다. 현재 폼·조건 변화가 이미 발사한 공격의 값을 소급 변경하지 않게 합니다.

### 발동 순서와 재귀 방지

`입력 가능 여부·SP 확인 → SP 1회 차감 → 폼 변경·2초 쿨타임 시작 → 전환 성공 이벤트 1회 → 해당 스킬 수치 고정·발동` 순서를 제안합니다. 성공 이벤트 기반 버프는 그 전환 스킬부터 적용하며, SP 조건이 있으면 차감 후 값을 검사합니다. 미스나 동작 중단은 이미 성공한 전환을 실패 입력으로 바꾸지 않습니다.

- 이 초안의 효과는 능력치 변경과 유한한 버프만 사용하며, 즉시 SP 환급·효과가 생성하는 추가 공격·추가 전환은 넣지 않는 방향을 제안합니다.
- 실패·허브 시작 폼 선택·저장 복구·단순 수치 재계산은 전환 성공 이벤트를 만들지 않습니다.
- 같은 소스의 시간제 버프는 1중첩이며 재발동하면 남은 시간을 지정 시간으로 갱신합니다. 시간 합산과 무한 중첩을 하지 않습니다.
- 구매·판매·합성 결과의 보유 목록을 확정한 뒤 효과와 시너지를 한 번 재계산하는 방식을 제안합니다. 중간 소유 상태로 획득·해제 이벤트가 반복되지 않게 합니다.
- 비용 하한과 재생 상한으로 비용 0·과도한 재생을 제한합니다. 최적 조합의 지속 전환·회피 가능 여부는 아래 SP 경제 테스트에서 확인합니다. 초안 수치만으로 밸런스가 검증됐다고 보지 않습니다.

## 일반 적 3종 제안·검토 대기

기본 수치는 1층 기준입니다. 모든 공격 피해는 오행 배율 적용 전 값입니다. 같은 원형에 목·화·토·금·수 중 하나를 부여하되, 전투 시작 후 바꾸지 않습니다. 방 오행을 일반 적 오행으로 사용하는 방식을 제안하며 확정 사항은 아닙니다. 외형 15종 제작을 뜻하지 않습니다.

공통 제안: 예고 종료 시 공격 방향을 고정하고 추적하지 않습니다. 일반 적의 층별 HP는 `기본 × [1+0.20×(층-1)]`, 피해는 `기본 × [1+0.10×(층-1)]`로 증가시키며 속도·타이밍은 유지합니다. 체력·피해는 소수 상태로 계산하고 UI에서만 반올림하는 방식을 제안합니다. 사망 시 보유 투사체까지 제거하는 범위는 기본적으로 해당 적 소스로 추적합니다. 방 구성·적 수·등장 위치·한 번에 등장할 수는 별도 검토 대상입니다.

일반 적 처치 골드는 확정 규칙대로 `층+4`를 즉시 지급합니다. 공격별 체력 피해에 SP 피해를 추가하지 않습니다.

## 아이템 20개 데이터 초안

**확정:** 목·화·토·금·수별 4개, 각 오행에 1~4등급 한 개씩입니다. 등급별 구매가는 20/40/80/160골드입니다. 동일 ID는 런당 최대 한 개, 보유 즉시 패시브 적용이며 기본 적용 대상은 모든 폼입니다.

**제안 / 검토 대기:** 아래 ID·표시 이름·아이콘 키·태그·개별 효과와 수치·지속 시간 및 효과 연산 규칙입니다. 이 표를 승인된 밸런스로 취급하지 않습니다. 아이템 오행은 획득 풀과 시너지 분류이며, 아래의 단순 능력 증가로 공격의 원래 오행을 변경하지 않습니다.

### 공통 데이터와 사건 정의 — 제안 / 검토 대기

- 각 행의 조건은 소지 중에만 유효합니다. 적용 대상은 플레이어의 모든 폼이며 폼 전용 조건은 없습니다.
- `보유`는 소지 중 연속 적용입니다. `성공 전환`은 던전에서 SP 결제 및 실제 다른 폼으로의 변경을 완료한 사건 `OnFormSwitchSucceeded`를 의미합니다. 같은 폼 재선택·SP 부족·쿨타임 중 입력·행동 제한 중 입력·허브 폼 선택은 이 사건을 발생시키지 않습니다.
- 각 아이템의 효과는 **소스 ID별 1중첩**입니다. 지속 버프가 재발동하면 값은 늘리지 않고 남은 시간을 표의 전체 지속 시간으로 갱신합니다. 남은 시간에 시간을 더하지 않습니다. 시간은 게임 진행 시간이며 일시정지 동안 줄어들지 않습니다.
- `보유 중` 효과는 판매·합성 재료 소비·런 초기화로 소지 조건이 사라지면 즉시 제거합니다. 시간제 효과도 소스 아이템 제거 시 즉시 제거하며, 그 밖에는 만료 시 제거합니다. 이후 재획득해도 삭제한 버프를 복구하지 않습니다.
- 서로 다른 ID의 같은 종류 수치는 공통 효과 합산식에 전달합니다. 아래 `+%`는 해당 피해 종류 또는 최대 HP의 가산 보정값이며 독립 곱연산으로 반복하지 않습니다. `SP/초`와 `SP 비용 감소`는 절대량입니다. 합산 기준·비용 하한·최대치 변경 시 현재 자원 처리·공격 시점의 값 고정은 통합 초안의 공통 연산 규칙을 따릅니다.
- 최대 HP 또는 최대 SP 증가는 즉시 체력/SP 지급 효과가 아닙니다. 효과 제거 시 줄어든 최대치를 넘어선 현재 값은 공통 상한 처리로 제한하며, 판매·재획득을 회복 수단으로 쓰지 않도록 합니다.
- 아이콘 키는 `icon.<ID>`로 제안하며 실제 이미지 제작은 미정입니다. 표의 이름을 임시 표시 이름으로 사용하고, 효과·조건·지속 시간을 그대로 설명문에 표시합니다.
- 태그는 오행에 따라 `ITEM_WOOD`, `ITEM_FIRE`, `ITEM_EARTH`, `ITEM_METAL`, `ITEM_WATER` 중 하나입니다. 태그 자체는 추가 효과를 발생시키지 않습니다. 시너지 조합은 별도 표의 정확한 아이템 ID 집합으로 판정합니다.

### SP 운용 의도와 한계 — 제안 / 검토 대기

목은 SP 저장량과 전환 후 재생, 화는 전환 이후 일반 공격, 토는 생존과 회피 부담, 금은 전환 스킬 피해, 수는 지속적인 SP 순환에 중점을 둡니다. 오행은 아이템 효과를 사용할 수 있는 폼을 제한하지 않습니다.

- 최대 SP를 늘려도 고갈 후 재생 속도가 자동으로 빨라지지는 않습니다. 재생 아이템과 소모 감소 아이템은 별도로 선택합니다.
- 재생 보정은 승인된 마지막 소비 후 1초 지연을 단축하거나 무시하지 않습니다. 전환 후 재생 버프 3초 중 첫 1초는 해당 지연과 겹칠 수 있습니다. 버프가 SP를 직접 지급하지 않습니다.
- 어떤 아이템도 전환 공통 쿨타임 2초, 회피 동작 시간·거리·무적 시간을 변경하지 않습니다. 회피·전환 SP 비용 감소는 해당 행동을 실행할 때만 적용되며 소비 자체를 SP 획득 사건으로 바꾸지 않습니다.
- 아이템만 모두 보유한 가상의 합산 점검값은 최대 SP 145, 상시 재생 30 SP/초, 회피 비용 15, 전환 비용 6입니다. 목 4등급 버프 동안 재생은 38 SP/초, 토 4등급 버프 동안 회피 비용은 11입니다. 이는 강화·시너지 제외 산술 점검값이며 완성 빌드의 확정 밸런스가 아닙니다.
- SP 즉시 환급·처치 재화 증가·별도 추가 공격·추가 전환은 없습니다. 동일 성공 전환 사건에 각 소스는 한 번만 반응하고, 버프 적용 자체는 새로운 전환 사건을 발생시키지 않는 방식을 제안합니다.

### 20개 풀의 시험 제약

한 오행에는 미보유 상태에서도 총 4개뿐이므로, 오행 지정 상점 새로고침은 처음부터 최대 4개만 진열할 수 있습니다. 한 번에 남은 후보 전부를 진열하면 등급 가중치는 진열 여부를 바꿀 수 없고 추첨 순서에만 영향을 줄 수 있습니다. 일반 방 2택1은 해당 오행 미보유 수가 1개면 단일 수동 선택, 0개면 선택 생략과 입장 전 안내를 빈번하게 시험해야 합니다. 각 오행의 4등급은 하나뿐이므로 목표 4등급 보유 시 해당 오행 합성이 차단되는 것도 정상 경계 사례입니다. 확정된 축소·생략·차단 규칙을 유지하며 이를 메우기 위해 새 아이템·중복 보유·자동 재입고를 추가하지 않습니다.

## 선택 강화 10종·시너지 5조합 제안·검토 대기

상태: **개별 이름·효과·수치·레벨 상한·적용 세칙 모두 제안/검토 대기**. 강화 10종(공통 5종과 각 폼 전용 1종), 시너지 5조합이라는 규모만 사용자 승인 사항입니다. 아래 값은 확정 방향 문서의 SP 100/재생 초당 20/소비 후 1초 지연/회피 20/전환 10/전환 공통 쿨타임 2초를 시험하기 위한 제안이며 기본 규칙을 대체하지 않습니다.

### 강화 공통 데이터와 적용 제안

- 아래 표의 모든 강화는 최대 레벨 **3 제안**입니다. L1/L2/L3는 해당 레벨의 최종 보너스이며, 같은 강화의 이전 레벨을 교체합니다. 예: +10%/+20%/+30%의 3레벨은 +30%이며 +60%가 아닙니다. 서로 다른 출처의 같은 능력치 보너스는 통합 명세의 가산식과 상한으로 합산합니다.
- 적용 조건은 해당 강화 레벨이 1 이상인 동안입니다. 지속은 런의 해당 강화 보유 기간이며 시간제 버프가 아닙니다. 사망·포기 시 해당 강화가 초기화되어 해제됩니다. 클리어 후 런 자원 처리는 확정 문서의 미정 상태를 유지합니다. 재접속은 저장한 ID·레벨에서 상태를 복원하고 획득 효과를 재지급하지 않습니다.
- 강화는 판매·합성 재료가 아닙니다. 아이템의 최대 1개 보유 규칙 대신 같은 강화 재선택 시 레벨 증가 규칙을 따릅니다. 최대 레벨은 후보에서 제외합니다.
- 폼 전용 강화도 현재 사용 폼과 무관하게 후보로 나옵니다. 효과는 공격 시작 시 기록한 폼과 공격 종류가 표의 대상을 모두 만족할 때만 적용합니다. 이미 시작한 공격은 전환 후에도 기록한 속성과 폼을 유지하며, 뒤늦은 폼 전환이 그 공격을 다른 전용 강화 대상으로 바꾸지 않습니다.
- 피해 보너스는 해당 공격의 강화·아이템 보너스 적용 전 기본 피해를 기준으로 한 가산 비율입니다. 오행 상성 배율의 처리 순서는 통합 명세의 연산식에서 정의합니다. 추가 공격, 타격 횟수 증가, 상태 이상, 공격 속성 변경은 발생하지 않습니다.
- 최대 HP·SP 상승 시 현재 HP·SP를 즉시 채우지 않는 방식을 **제안**합니다. 감소 시 현재값이 최대값을 초과하면 최대값으로 제한하는 방식도 **제안**입니다. 이 문서의 공통 수식에서 다른 최대치 효과와 동일한 규칙으로 검토합니다.
- UI는 현재 레벨 → 다음 레벨과 현재 실제값 → 획득 후 실제값을 표시합니다. 최대 레벨에는 최대 표시를 사용합니다. 아이콘 키는 `icon.<ID>` 형식의 임시 데이터 키로 제안하며 실제 이미지 제작은 별도입니다. 표시 설명은 다음 레벨의 효과량을 대입해 사용합니다.

### 시너지 공통 데이터와 적용 제안

- 아래 각 조합의 **서로 다른 아이템 ID 2개를 모두 현재 보유**하면 자동 활성화합니다. 재료 소비나 별도 버튼은 없습니다. 이 조건은 확정된 동시 보유 시너지 방식에 맞춘 구체 조합 **제안**입니다.
- 모든 시너지는 전체 폼에 적용하는 정적 효과입니다. 시너지 ID별 최대 1회 적용하며 같은 시너지를 중복 생성하지 않습니다. 여러 시너지는 동시에 적용할 수 있습니다.
- 지속 시간은 두 아이템을 모두 보유한 기간입니다. 판매·합성 소비로 하나라도 없어지면 같은 거래 결과에서 즉시 해제하고 능력치를 재계산합니다. 사망·포기의 아이템 초기화도 동일합니다. 재접속 시 보유 ID로 재계산합니다.
- 효과 수치는 원천별 보너스 합산에 참여합니다. 같은 수치의 합산 상한·비용 하한은 통합 명세에서 일괄 검토합니다. 전환 공통 쿨타임 2초·재생 지연 1초·공통 회피 성능·소비 실패 규칙은 바꾸지 않습니다.

### 강화·시너지 검증 포인트

- 강화 ID는 공통 5개와 오행 전용 5개, 총 10개이며 서로 다릅니다. 3레벨 제안 적용 시 가능한 강화 획득 총량은 30회입니다. 확정된 일반 전투 구역 25개에서 총 25회 선택 가능하므로 단일 런 전체 강화 최대치 동시 달성은 가정하지 않습니다.
- 시너지 ID는 5개이며 각각 동일 오행의 1·2번 아이템을 요구합니다. 해당 아이템들의 효과와 별도로 적용하고, 아이템 등급/가격/추첨/합성 규칙은 변경하지 않습니다.
- SP 관련 공통 강화와 시너지는 정적인 최대치·재생·비용 조정으로 제한했습니다. 연쇄 타격·SP 환급이 없어 이 묶음만으로 이벤트 재귀나 소비 즉시 반환 루프가 생기지 않습니다. 다른 아이템 효과와 합친 최저 비용·최고 재생량은 통합 검증 대상입니다.
- 동일 강화 재선택은 기존 레벨 보너스를 제거하고 새 레벨 보너스를 1회 적용하는 결과여야 합니다. 저장 복원·인벤토리 재계산을 반복해도 보너스가 누적되지 않아야 합니다.
- 최대치 증가를 회복으로 사용하지 않는 제안은 아이템 매매/합성·재접속을 통한 반복 회복을 막기 위한 세칙이며 아직 승인되지 않았습니다.
