# 벽 부착물 프리팹 만들기

벽등·문 위 조명·비상구 표시·액자·환기구·모니터·선반 같은 개별 부착물과, 배관·케이블·몰딩처럼 연결되는 부품을 같은 방식으로 등록합니다. 실제 메시, Light, 머티리얼, 게임용 Collider는 Unity 프리팹에 넣고, `BaekhoWallModule`은 설치 기준과 연결점만 지정합니다.

## 배관·케이블의 자동 배치 높이

**벽 부착물 자동 배치**와 **현재 맵 · 벽 부착물 추가**에서 같은 높이 설정을 사용합니다. 실제 프리팹과 임시 배관 모두에 적용하며, 등록한 에셋 자체의 높이 설정을 바꾸지는 않습니다.

1. **가로 배치 높이**에서 **프리팹 기본값**, **지정 높이**, **범위 내 무작위** 중 하나를 선택합니다. 높이는 부착점 기준이며, **인접 바닥에서 위로** 또는 **벽 상단에서 아래로** 거리를 입력합니다. 같은 수평 연결 구간은 같은 높이에 놓이고, 서로 분리된 구간은 시드에 따라 다른 높이가 선택됩니다.
2. **세로 배관 높이 범위**는 기본 **전체 높이**입니다. **지정 범위**에서는 시작 거리보다 끝 거리를 크게 입력합니다. 예를 들어 바닥 기준 0.5~3m는 바닥 위 해당 구간이며, 상단 기준 0.5~3m는 벽 상단에서 0.5~3m 아래 구간입니다.
3. 세로 범위는 끝마감을 포함한 부품 전체에 적용합니다. 부품을 늘이거나 줄이지 않고 조립하므로, 지정한 범위를 모두 채우지 못하면 여백을 남깁니다. 엘보·T자 연결점과 세로 분기가 범위에 맞지 않으면 연결하지 않고 결과에 이유를 표시합니다.
4. 새 맵을 생성하거나 **현재 맵에 벽 부착물 자동 배치**를 실행하면 새 배치에 적용합니다. 이미 있는 자동 배관에 적용하려면 **현재 높이 설정으로 자동 배관 재배치**를 누릅니다. 현재 방향·높이·밀도로 다시 구성하고, 수동 편집·프리팹 교체·복사·잠금·시설 참조가 있는 구간은 전체를 보존합니다.
5. 재배치 결과에서 재배치·보존·제외 구간을 확인합니다. 결과를 만들 수 없거나 최종 검증이 실패하면 기존 맵을 유지합니다. 성공한 재배치는 한 번의 Undo/Redo로 복원할 수 있습니다.

설정 변경만으로 현재 배관은 이동하지 않습니다. 특정 구간만 옮기려면 기존 선택 편집의 **높이 이동**을 사용하세요. 높이 설정이 없는 예전 프로젝트는 기존 프리팹 기준과 세로 전체 길이를 유지합니다.

## 프리팹 없이 배치를 먼저 확인하기

0.6.2부터 실제 프리팹을 준비하기 전에도 임시 벽등·문 위 조명·패널·환기구와 연결 배관으로 배치를 확인할 수 있습니다.

1. **벽 부착물 자동 배치**에서 **생성 시 벽 부착물 배치**와 **프리팹이 없으면 임시 벽 부착물로 배치**를 켭니다. 임시 배치는 기본 켜짐이며 **벽등·문 조명·개별 장식**, **배관·케이블·연속 부품**을 각각 검사해 해당 종류의 벽용 에셋이 하나도 등록되지 않았을 때 사용합니다. 이미 등록한 에셋이 미측정 상태이거나 설치 확률이 0인 경우에는 설정 원인을 안내합니다.
2. 새 맵을 생성하거나, 기존 맵에서 **현재 맵에 벽 부착물 자동 배치**를 누릅니다. 임시 형상도 실제 벽·문 위 마감·높이·겹침·통행 여유를 검사합니다. 문 위 공간이 부족하거나 배관을 연결할 수 없는 부분은 비워 둡니다.
3. 미리보기에서 **임시** 부착물을 선택하고 높이·벽을 따라 이동·벽에서 띄우기를 조정합니다. 연결된 배관의 이동은 구간 전체에 적용합니다. 위치와 임시 종류는 맵에 저장되며, 저장 후 다시 열거나 Undo/Redo를 실행해도 유지됩니다. 임시 항목은 실제 Unity 에셋 참조를 만들지 않고 배치 정보로 저장합니다. 임시 조명은 위치와 기구 크기 확인용이며 게임용 Light는 포함하지 않습니다.
4. 실제 프리팹을 아래 순서로 등록한 뒤 임시 부착물을 다시 선택합니다. **선택한 하나에 사용할 프리팹** 목록의 **임시 유지 · 실제 프리팹 선택**에서 사용할 에셋을 고르면 원래 설치점을 기준으로 교체하고 크기·충돌을 다시 검사합니다. 같은 역할과 설치 위치의 호환 에셋만 선택할 수 있습니다. 프리팹 등록이나 자동 배치 재실행만으로 기존 임시 항목이 교체되지는 않습니다.

임시 직선 배관의 **Socket 사이 유효 길이는 1m**이며, 왼쪽 Socket은 `(-0.5,0,0.1)`에서 -X, 오른쪽은 `(0.5,0,0.1)`에서 +X를 향합니다. 연결 구간 안에서 교체하려면 직선·안쪽 코너·바깥쪽 코너·끝마감의 종류와 실제 연결점 위치·방향이 맞아야 합니다. 같은 구간의 실제 부품은 같은 Family를 사용합니다. 2m 직선이나 다른 접속 위치·단면 규격을 쓰려면 임시 배관 구간을 제거한 뒤 실제 프리팹 세트로 다시 자동 배치하세요. 교체 때문에 모델이나 구간 길이를 늘이거나 줄이지 않습니다.

임시 배치를 그만 사용하려면 **프리팹이 없으면 임시 벽 부착물로 배치**를 끕니다. 이미 저장한 임시 항목은 남으므로 필요한 항목을 선택해 교체하거나 **벽 부착물 제거**를 실행합니다. **Unity ZIP 내보내기 전에는 임시 항목을 모두 실제 프리팹으로 교체하거나 제거해야 합니다.** 임시 배치가 남은 상태로도 맵 저장과 편집은 가능합니다.

## 같은 종류의 임시 부착물을 한 번에 교체하기

0.6.3부터 같은 임시 종류를 맵 전체에서 일괄 교체할 수 있습니다.

1. 교체할 종류의 임시 부착물을 하나 선택합니다. 예를 들어 임시 직선 배관을 선택하면 가로·세로 방향의 임시 직선 배관 전체 개수를 표시합니다.
2. **같은 종류 전체에 사용할 프리팹**에서 **전체 교체할 실제 프리팹 선택**을 열고 등록한 호환 에셋을 고릅니다. 이 선택은 교체할 실제 프리팹을 지정합니다.
3. **같은 종류 N개 한 번에 교체**를 누릅니다. 맵 전체의 같은 임시 종류만 교체하며, 이미 실제 프리팹인 항목과 다른 임시 종류는 유지합니다. 예를 들어 직선 배관을 교체해도 안쪽 코너·바깥쪽 코너·끝마감은 임시 상태로 남으므로 각각 선택해 교체합니다.

일괄 교체는 모든 대상의 잠금·설치 위치·크기·충돌·연결점과 같은 구간의 Family를 검사합니다. 한 항목이라도 교체할 수 없으면 실패 이유를 표시하고 **전체 변경을 취소해 기존 맵을 유지**합니다. 성공한 교체는 **되돌리기(Ctrl+Z) 한 번**으로 모두 복원할 수 있습니다. 하나만 바꾸려면 위쪽의 **선택한 하나에 사용할 프리팹**을 사용합니다.

## 배관을 가로·세로로 배치하기

**배관·케이블 배치 방향**에서 다음 중 하나를 선택합니다.

| 선택 | 배치 방식 |
|---|---|
| **가로 · 벽을 따라 연결** | 벽을 따라 직선·수평 코너·끝마감을 연결 |
| **세로 · 벽을 타고 상승** | 벽면 위·아래 방향으로 직선을 연결하고 양 끝을 마감 |
| **가로와 세로 함께** | 연결 옵션을 켜면 가로 구간에서 엘보·T자로 세로 배관을 연결 |

설정은 새 맵 생성과 **현재 맵에 벽 부착물 자동 배치**에 적용합니다. 기존 방향 설정이 없는 프로젝트는 가로 배치를 유지하며, 설정을 바꿔도 이미 배치한 부품을 회전시키지는 않습니다. 세로 구간도 실제 벽 높이와 부품 길이·겹침·통행 여유를 검사하고 원본 크기를 유지합니다. 남는 높이를 채우려고 부품을 늘이지 않습니다.

**연속 배치 목표 (%)**는 가로에서 벽 길이, 세로에서 설치 가능한 벽면 수를 기준으로 합니다. 세로 자동 배치는 바닥·천장·기존 물체 사이의 빈 높이 구간에 양 끝을 마감한 관을 넣습니다. 에셋의 설치 높이는 가로 배관과 개별 부착물에 적용하며, 배치된 세로 구간을 옮기려면 선택 후 **높이 이동량 (m)**을 조절합니다.

**원본 프리팹은 아래의 가로 제작 규칙을 그대로 사용합니다.** 직선은 로컬 X를 따라 만들고 Mount는 +Z 실내 방향, Socket은 양 끝의 바깥 방향으로 지정합니다. 앱은 이 직선과 끝마감을 벽면 안에서 **로컬 Z축으로 90°/270° 회전**해 세로로 사용합니다. 가로용 원본 프리팹을 별도의 세로 메시로 다시 만들 필요는 없습니다. 이 회전은 맵에 저장되어 다시 열기·Undo/Redo·Unity 내보내기에 반영되며 호환 프리팹 교체에서도 유지됩니다.

0.6.4부터 **가로와 세로 함께**를 선택하고 **가로·세로 배관 연결 (엘보·T자)**을 켜면 가로 구간에서 세로로 꺾거나 분기합니다. 연결 옵션은 기본 켜짐이며, 끄면 위·아래가 마감된 독립 세로 구간을 배치합니다. 설정 변경 후 **현재 맵에 벽 부착물 자동 배치**를 실행하세요. 임시 배치에도 **임시 가로·세로 엘보**, **임시 T자 분기관**을 사용하므로 실제 프리팹 등록 전에 연결 형태를 볼 수 있습니다.

연결된 가로·세로 배관은 하나의 구간으로 편집하고 각 Socket에는 상대 Socket이 정확히 하나씩 붙습니다. 삭제나 분리로 열린 끝은 마감 가능 여부를 검사합니다. 잠금·수동 수정된 구간은 자동 배치에서 보호하며, 벽의 빈 공간이나 호환 부품이 부족해 연결되지 않으면 결과 안내를 확인하세요. 실제 세트에 연결 부품이 빠졌을 때 임시 부품을 끼워 넣지는 않습니다. 벽 자체의 안쪽·바깥쪽 모서리는 아래의 수평 코너 규칙을 사용합니다.

## 가로·세로 엘보와 T자 분기관 만들기

Unity의 `BaekhoWallModule.cs`와 `BaekhoPropCatalog.cs`를 0.6.4 파일로 갱신합니다. **Kind = Elbow / Tee**, **Sites = Wall**, **Mount 1개**를 사용합니다. 이 부품들은 한 벽면 안에서 가로·세로를 연결합니다. 두 벽의 모서리를 도는 `Inner Corner / Outer Corner`와는 종류가 다릅니다.

임시 배관을 그대로 교체할 수 있는 예시입니다. 루트는 벽 접촉면 중앙, Mount는 `(0,0,0)`에서 +Z, 관 중심은 벽에서 0.1m 떨어진 `(0,0,0.1)`입니다. 모든 Socket 자식의 **파란 +Z 화살표**가 표에 적힌 바깥 방향을 향하도록 회전합니다.

| Socket | 위치 | 바깥 방향 | 사용할 부품 |
|---|---|---|---|
| 왼쪽 | `(-0.5,0,0.1)` | -X | Elbow, Tee |
| 오른쪽 | `(0.5,0,0.1)` | +X | Tee |
| 아래쪽 | `(0,-0.5,0.1)` | -Y | Elbow, Tee |

Elbow는 서로 수직인 Socket 2개, Tee는 반대 방향인 한 쌍과 수직 분기 Socket을 합쳐 3개를 지정합니다. 각 Socket은 같은 벽면 평면 안에 있어야 하며, 방향을 거슬러 안쪽으로 따라가면 같은 관 중심에서 만나는 구조여야 합니다. 같은 Family의 직선·끝마감과 관 지름·벽에서 떨어진 거리·접속 단면을 맞추세요. 앱은 벽 방향과 로컬 Z 회전을 적용하므로 위쪽·아래쪽 방향마다 원본을 따로 만들 필요는 없습니다.

**Collision Boxes는 Elbow 최소 2개, Tee 최소 3개**를 직접 지정합니다. 팔마다 얇은 상자를 넣어 빈 공간을 점유하지 않게 합니다. 임시 부품의 예시는 다음과 같습니다. 실제 메시의 두께·브래킷·플랜지가 다르면 그 크기를 정확히 반영해야 합니다.

| 팔 | 상자 중심 | 상자 크기 | 사용할 부품 |
|---|---|---|---|
| 왼쪽 | `(-0.25,0,0.1)` | `(0.5,0.1,0.2)` | Elbow, Tee |
| 오른쪽 | `(0.25,0,0.1)` | `(0.5,0.1,0.2)` | Tee |
| 아래쪽 | `(0,-0.25,0.1)` | `(0.1,0.5,0.2)` | Elbow, Tee |

필요하면 곡선과 접합부를 감싸는 작은 상자를 추가합니다. 큰 상자 하나로 ㄱ/T자의 빈 부분까지 채우면 다른 관과 충돌한 것으로 판단할 수 있습니다. 이 상자는 자동 배치 검사에 사용하며 게임용 Collider는 프리팹에서 별도로 만듭니다.

완성한 프리팹만 선택해 **Assets → Baekho → Export Prop Bounds Catalog**로 내보낸 뒤 앱의 **크기 가져오기 · 프리팹 일괄 등록**에서 **장식**으로 가져옵니다. 임시 엘보 또는 T자를 선택해 **같은 종류 전체에 사용할 프리팹**으로 일괄 교체합니다. 피벗이 달라도 설치 후 Socket 위치·방향과 크기·충돌 조건이 맞으면 교체할 수 있습니다.

## 준비와 공통 좌표

1. 앱이 내보낸 ZIP의 `Unity/Editor` 파일 두 개를 Unity의 `Assets/Baekho/Editor`에, `Unity/Runtime` 파일 네 개를 `Assets/Baekho/Runtime`에 복사합니다. 기존 임포터는 같은 위치의 파일로 갱신합니다. `BaekhoWallModule.cs`도 필요하며 Runtime 파일을 Editor 폴더 안에 넣지 않습니다.
2. 모델은 **Unity 1단위 = 1m**, **+Y 위쪽**으로 만듭니다. 프리팹 루트의 Rotation은 `(0,0,0)`, Scale은 `(1,1,1)`을 권장합니다. 메시 크기는 자식에서 맞추거나 모델 도구에서 적용합니다. 등록한 배율을 곱한 크기를 고정해서 조립하므로 부품별 임의 배율로 이음새를 맞추지 않습니다.
3. 원본 프리팹 루트에 **Add Component → Baekho → Wall Module**을 추가합니다. `Mounts`, `Sockets`에 사용할 자식 Empty GameObject를 만들고 배열에 드래그합니다. 선택하면 Mount는 청록색, Socket은 자홍색 화살표, 충돌 상자는 노란 선으로 보입니다.
4. 기준 벽을 로컬 `Z = 0`, 실내를 **+Z** 쪽으로 생각하면 쉽습니다. 부착점 `Mount`의 위치는 벽 접촉면, 파란 **+Z 화살표는 실내 방향**입니다. 연결점 `Socket`은 관 끝 단면의 중심, 파란 **+Z 화살표는 부품에서 바깥으로 뻗는 방향**입니다. 연결되는 두 Socket은 같은 위치에서 서로 반대 방향이어야 합니다.

피벗을 반드시 관의 중앙에 둘 필요는 없습니다. 내보내기는 프리팹 루트 기준 메시 경계의 **중심과 크기**, 모든 Mount/Socket 좌표를 함께 저장하므로 치우친 피벗도 지원합니다. 아래 예시는 이해를 위해 피벗을 벽 접촉면 중앙에 둡니다. 기존 직선·수평 코너·끝마감의 **원본 프리팹** Mount/Socket 방향은 로컬 X/Z의 네 방향 중 하나로 지정합니다. 세로 배치는 앱이 수평 원본을 회전해서 만듭니다. 새 `Elbow / Tee`는 벽면 안의 ±Y Socket도 허용합니다. 비스듬히 기울어진 연결과 45° 연결은 지원하지 않습니다.

## 직선 배관 1m와 2m

권장 프리팹 구조입니다. Empty에는 Renderer나 Collider를 넣지 않습니다.

```text
Pipe_Straight_1m                 BaekhoWallModule
├─ Visual                       메시, 머티리얼, 게임용 Collider
├─ Mount                        벽 접촉점
├─ Socket_Left                  왼쪽 단면 중심
└─ Socket_Right                 오른쪽 단면 중심
```

관 지름 0.1m, 관 중심과 벽 사이 거리 0.1m인 예시입니다. `Visual`의 중심 높이는 0이고 관은 로컬 X를 따라 놓습니다. 원통 원본이 Y 방향이라면 Visual 자식만 Z로 90° 회전시킵니다.

| 항목 | 1m 직선관 | 2m 직선관 |
|---|---|---|
| Kind / Family | `Straight` / `FactoryPipe100` | `Straight` / `FactoryPipe100` |
| Mount 위치 / Y 회전 | `(0,0,0)` / `0°` → +Z | 동일 |
| 왼쪽 Socket 위치 / Y 회전 | `(-0.5,0,0.1)` / `270°` → -X | `(-1,0,0.1)` / `270°` |
| 오른쪽 Socket 위치 / Y 회전 | `(0.5,0,0.1)` / `90°` → +X | `(1,0,0.1)` / `90°` |
| 관의 유효 연결 길이 | 두 Socket 사이 1m | 두 Socket 사이 2m |
| 충돌 상자 예시 center / size | `(0,0,0.1)` / `(1,0.1,0.1)` | `(0,0,0.1)` / `(2,0.1,0.1)` |

`Sites = Wall`, `Height Mode = Top`, `Height = 0.5`면 벽 상단에서 0.5m 아래에 설치하는 설정입니다. 같은 Family의 직선·코너·마감은 관 지름, 접속 단면, 벽에서 떨어진 거리, 연결점 높이와 설치 높이 설정을 맞춥니다. 브래킷이나 플랜지가 메시에서 돌출돼도 **유효 길이는 메시 외접 크기가 아니라 Socket 사이의 거리**입니다. 플랜지가 접합부를 가로질러 겹치면 충돌 상자와 실제 메시도 접합 규격에 맞춰 조절합니다.

`Collision Boxes`가 비어 있는 단일·직선·마감 부품은 메시와 Collider를 합친 상자를 사용합니다. 브래킷이 크거나 복잡하면 실제로 차지하는 구역을 여러 상자로 직접 지정하세요. 이 상자는 자동 배치 점유 검사에만 쓰며 게임용 Collider를 생성하거나 수정하지 않습니다.

## 안쪽·바깥쪽 코너와 끝마감

관을 길게 늘여 모서리를 넘기지 않고, 모델링한 엘보 부품으로 90°를 연결합니다. `Inner Corner`와 `Outer Corner`는 서로 다른 지지 벽 방향을 가지므로 맞는 종류를 등록합니다. 코너는 Mount 2개와 Socket 2개가 필요하며 각각의 방향은 서로 수직입니다.

| 부품 | 두 벽 접촉점과 실내 방향 | 두 Socket과 바깥 방향 |
|---|---|---|
| 안쪽 코너 예시 | `(0.25,0,0)` → +Z, `(0,0,0.25)` → +X | `(0.5,0,0.1)` → +X, `(0.1,0,0.5)` → +Z |
| 바깥쪽 코너 예시 | `(0.25,0,0)` → +Z, `(0,0,-0.25)` → -X | `(0.5,0,0.1)` → +X, `(-0.1,0,-0.5)` → -Z |

이 예시는 모서리에서 각 Socket까지 0.5m를 사용하므로 1m/2m 직선과 조합하기 쉽습니다. 같은 Family의 직선과 같은 `Top / 0.5m` 설치 높이를 지정하고 엘보의 두 팔이 연결되는 곡률과 길이에 맞춰 메시를 만드세요. **코너에는 최소 2개의 Collision Box를 직접 지정합니다.** 각 팔을 감싸는 얇은 상자를 사용하고 안쪽 빈 사각형은 비워 둡니다. 안쪽 예시의 상자는 center `(0.25,0,0.1)`, size `(0.5,0.1,0.1)`와 center `(0.1,0,0.25)`, size `(0.1,0.1,0.5)`입니다. 바깥쪽 예시는 두 번째 팔 상자의 center를 `(-0.1,0,-0.25)`으로 바꿉니다. 곡선 메시를 더 잘 감싸려면 작은 상자를 추가할 수 있습니다.

끝마감은 `Kind = End Cap`, 같은 Family, **Socket 1개**를 지정합니다. Socket은 마개와 직선관이 접하는 중심에서 직선관 쪽을 향하게 합니다. 축 대칭 마개라면 **Mounts를 빈 배열로 두면** 좌우 끝에서 같은 프리팹을 수평 회전해서 사용할 수 있습니다. 벽 받침이 있어 실내 방향이 정해진 마감은 Mount 1개를 지정하고 좌·우용 프리팹을 각각 준비하세요. 권장 최소 세트는 **1m 직선 + 2m 직선 + 안쪽 엘보 + 바깥쪽 엘보 + 대칭 마개**입니다.

고정 길이 부품만 사용하므로 어떤 벽도 남김없이 채워지지는 않습니다. 예를 들어 코너·마감이 차지하는 길이를 뺀 뒤 남은 길이가 3.4m이면 2m + 1m를 사용하고 여백을 남깁니다. 0.5m 직선도 추가하면 더 촘촘히 채울 수 있습니다. 필요한 코너나 마감이 없거나 겹침 없이 조립할 수 없으면 해당 구간을 건너뛰며 부품을 찌그러뜨려 맞추지 않습니다.

## 벽등·문 위 조명·일반 부착물

연결하지 않는 일반 벽면·문 부착물은 `Kind = Single`, **Mount 1개, Sockets 빈 배열**입니다. Family는 비워도 됩니다. Mount는 모델 뒷면의 실제 벽 접촉점에 두고 +Z가 빛이나 장식이 보이는 실내 쪽을 향하게 합니다.

| 용도 | Sites | 설치 설정 예시 |
|---|---|---|
| 문 위 조명·비상구 표시 | `Door Top` | `Floor` 높이 0.25m: 문 개구부 상단에서 0.25m 위 |
| 문 옆 카드 리더·인터폰·벽등 | `Door Side` | `Door Side = Left / Right / Both`, `Floor` 높이 1.4m |
| 일반 벽등·액자·포스터 | `Wall` | `Center` 높이 0, `Spacing` 3m |
| 높은 환기구·스피커 | `Upper` | `Top` 높이 0.5m |
| 낮은 전기함·소화기 | `Lower` | `Floor` 높이 0.6m |
| 모서리 표지·코너 조명 | `Corner`만 선택 | 두 벽에 맞는 수직 방향의 Mount 2개, Sockets 없음 |

`Single + Corner`는 두 벽을 지지하므로 **서로 수직인 Mount 2개**를 지정합니다. 예를 들어 모델이 모서리에서 실내 +X/+Z 쪽에 있을 때 Mount A `(0.15,0,0)` → +Z, Mount B `(0,0,0.15)` → +X를 사용할 수 있습니다. 모델 점유 상자는 center `(0.15,0,0.15)`, size `(0.2,0.2,0.2)`처럼 두 벽 안으로 파고들지 않게 잡습니다. `Corner`를 일반 `Wall`이나 문 위치와 섞지 말고 용도별 프리팹 변형을 만드세요. ㄱ자 모서리 조명은 팔마다 점유 상자를 나누면 빈 부분도 사용할 수 있습니다.

높이의 기본 해석은 `Center = 벽 중앙 + Height`, `Floor = 바닥 + Height`, `Top = 벽 상단 - Height`입니다. **Door Top은 문 위 마감 부분을 설치 영역으로 사용**합니다. 따라서 `Floor = 문 개구부 상단 + Height`, `Center = 문 위 마감의 중앙 + Height`, `Top = 마감 윗면 - Height`가 됩니다. 문 위 마감 공간이 작으면 조명을 충분히 작은 크기로 만들거나 설치 높이를 조절합니다. `Spacing`은 원하는 간격(m), `Probability`는 설치 가능한 지점에 적용할 확률(0~100%)입니다.

프리팹에 원래 쓰던 Light를 그대로 넣습니다. 색·강도·범위·그림자와 발광 머티리얼은 임포터가 변경하지 않습니다. 메시 없는 Light 전용 프리팹은 크기를 측정할 수 없으므로 `Collision Boxes`에 작은 양수 크기 상자를 직접 입력합니다. 광원의 Range 전체를 점유 상자로 잡지 말고 조명 기구가 차지하는 공간만 입력하세요. 선반처럼 튀어나온 물건은 점유 상자에도 돌출 깊이를 포함해야 통행 공간과의 겹침을 피할 수 있습니다.

## 앱에 등록하고 확인하기

1. Unity **Project 창에서 등록할 `.prefab`만 직접 선택**하고 **Assets → Baekho → Export Prop Bounds Catalog**를 실행합니다. 폴더나 Hierarchy 오브젝트를 선택하면 안내 후 중단하며 선택하지 않은 에셋을 자동 검색하지 않습니다.
2. 앱에서 해당 Unity 프로젝트를 연결하고 **에셋 → 크기 가져오기 · 프리팹 일괄 등록**으로 JSON을 가져옵니다. **일괄 등록할 새 에셋의 종류**에서 조명은 **조명**, 배관·케이블·일반 장식은 **장식**을 선택하고 벽 부착 정보와 원본 크기가 표시되는지 확인합니다. 다른 종류는 JSON을 따로 내보내 가져오면 편합니다. 예전 v1 크기 JSON도 읽지만 Mount/Socket은 포함하지 않습니다.
3. **에셋** 또는 **영역·배치**의 **현재 맵에 벽 부착물 자동 배치**를 실행합니다. 새 맵에도 생성하려면 **생성 시 벽 부착물 배치**를 별도로 켭니다. 문 위/문 옆 부착물, 일반 부착물, 연속 부품에 사용할 프리팹을 각각 확인합니다. 같은 Family라도 다른 지름·단면의 부품은 섞지 않습니다.
4. 미리보기에서 문을 가리지 않는지, 바닥 가구와 공존하는지, 모서리가 연결되는지 검사한 뒤 맵 ZIP을 내보냅니다. Unity에서 새 `.baekhomap.json`으로 **Build Prefab**을 실행하고 실제 메시·충돌체·조명과 이동 경로를 확인합니다.
5. 원본 프리팹의 크기·Mount·Socket을 바꿀 때는 기존 맵에 설치한 해당 부착물을 먼저 삭제하거나 다른 에셋으로 교체한 뒤, 카탈로그를 다시 내보내 앱에 가져옵니다. 설치된 물건의 측정값과 연결점이 달라지면 기존 연결을 보호하기 위해 가져오기를 거부합니다. 새 규격으로 다시 배치하고 맵 ZIP을 내보내세요. 이미 생성한 Unity 맵 프리팹도 새 JSON으로 다시 만들어야 바뀝니다.

내보내기 오류가 나면 컴포넌트가 프리팹 루트에 하나만 있는지, Transform 참조 개수와 파란 화살표 방향이 맞는지, Family가 같은지, 상자 크기가 모두 0보다 큰지 확인합니다. NaN/Infinity, 45° 또는 종류에 맞지 않는 연결점, 코너·엘보·T자의 누락된 팔별 상자도 거부합니다. 내보내기는 원본 프리팹의 Light·Collider·내부 자식 구조를 수정하지 않습니다.

## 자동 생성했는데 벽 부착물이 0개일 때

- **생성 배치가 꺼짐**: 기존 프로젝트에는 새 기능이 자동으로 켜지지 않습니다. `생성 시 벽 부착물 배치`를 켜세요. `현재 맵에 벽 부착물 자동 배치` 버튼은 현재 맵에 한 번 적용하는 기능이며 다음 생성 설정은 바꾸지 않습니다.
- **벽용 등록이 0개**: 0.6.2부터 `프리팹이 없으면 임시 벽 부착물로 배치`를 켜면 임시 형상으로 배치를 확인할 수 있습니다. 실제 프리팹을 쓰려면 에셋의 `벽 부착 자동 배치에 사용`을 켜고 크기·설치 위치를 설정합니다. 일반 장식 등록만으로는 벽용 에셋이 되지 않으며, 연결 배관은 Unity의 Mount/Socket 정보를 함께 가져옵니다.
- **0.6.0에서 기본 소품으로 가져옴**: 벽 정보가 저장되지 않았을 수 있습니다. 에셋 종류를 장식 또는 조명으로 바꾸고 원본 v2 JSON을 다시 가져옵니다. 0.6.1부터는 이 조합을 안내하고 가져오기를 취소합니다.
- **크기 확인이 0개**: 등록한 실제 프리팹은 실제 크기 또는 충돌 상자가 필요합니다. 프리팹 이름으로 크기를 추정하지 않습니다. 해당 종류에 벽용 에셋이 등록된 경우 미측정 에셋을 임시 형상으로 대신하지 않습니다.
- **등록과 옵션이 정상인데 0개**: 생성 결과 패널의 제외 이유를 확인합니다. 문 위 마감의 높이 부족, 벽보다 큰 프리팹, 낮게 돌출된 물건과 통행 공간의 겹침, 필요한 코너·끝마감 누락 등이 원인이 될 수 있습니다. 설정을 조정한 뒤 현재 맵 자동 배치로 확인하면 AI를 다시 호출할 필요가 없습니다.
