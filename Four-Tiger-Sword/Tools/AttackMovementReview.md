# 공격 전진 점검 — 2026-10-02

> 아래는 최초 점검 당시 기록이다. 후속 수정으로 타깃이 있는 일반/공통 강공격은 지속 추적(기본 6m/s, 720도/초)을 사용한다. 1·2·5번의 기존 커브/회전 중단 문제는 이 경로에서 개선했다. 타수별 이동 상한과 허공 공격은 유지된다. 현재 설정은 AttackMovementGuide.md 참고.

현재 소스와 Unity가 로드한 폼 데이터를 조사한 결과다. 아래 전진 구현과 튜닝 값은 이번 작업에서 변경하지 않았다. 실제 플레이 영상으로 체감을 확인한 결과는 아니며, 코드 및 Edit Mode 검사에 근거한다.

## 확인한 문제와 조건

1. **물 2·3타의 이동이 짧은 시간에 몰린다.** 모든 현재 일반 공격은 `UseDistanceMovement=false`여서 기존 Thrust 커브를 적분한다. `AttackMotionProfile.Reset`은 0초부터 접근 종료까지의 거리를 계산한 뒤 회전 준비 시간을 제외한 구간에 재생한다. 물 2타는 0.0333~0.1333초에 약 1.7626m(평균 17.6m/s), 물 3타는 같은 구간에 약 1.6830m다. 공격 속도 배율 1, 충돌과 정지 간격 제한이 없는 조건이다. 물 3타의 첫 타격은 0.43초여서 전진 종료와도 0.297초 떨어져 있다. 해결 방향: 거리 모드에서 타수별 이동 시작·끝과 총 거리를 직접 맞춘다.

2. **회전 종료 후 움직이는 적을 따라가지 못하고 접근이 끊길 수 있다.** `BaseForm.Motion.UpdateAttackFacing`은 `_rotationDeadline` 이후 회전하지 않는다. `LimitTargetApproach`는 적 방향과 몸 방향이 `ApproachAlignmentAngle`(기본 15도)보다 벌어지면 요청 이동을 0으로 만든다. 그동안 이동 시간은 계속 소비된다. 적이 옆으로 이동하면 전진이 갑자기 끊기고 남은 거리가 소실되는 구조다. 해결 방향: 접근 중 제한된 추적 회전을 허용하거나, 공격 시작 방향으로 고정 전진할지 정책을 통일한다.

3. **선택 가능한 거리와 도달 가능한 거리가 다르다.** 타깃 검색 반경은 10m지만 일반 공격의 `MaxApproachDistance`는 모두 2m다. 화면 중심의 먼 적을 선택해도 공격 범위까지 도달한다는 보장이 없다. 이번 시점 우선 선택에서는 특히 눈에 띌 수 있다. 해결 방향: 타깃 후보를 공격별 도달 범위로 제한하거나, 먼 적을 바라보기만 할 때와 실제 접근할 때를 구분한다.

4. **적이 없어도 전진한다.** 모든 현재 일반 공격의 `UntargetedDistanceMultiplier`는 1이다. 따라서 전진 데이터가 있는 폼은 허공 공격에도 동일한 요청 거리를 사용하고 최대 2m 상한만 적용한다. 입력하지 않은 이동처럼 느껴질 수 있다. 해결 방향: 허공 공격 배율을 0 또는 작은 값으로 설정한다.

5. **폼별 전진 설정이 일관되지 않다.** 목·금 일반 공격은 `ThrustMultiplier=0`이라 요청 전진 거리가 0이다. 토 1타는 약 1.853m/0.125초, 토 2타는 약 1.617m/0.15초이며, 토·금의 일반 공격 AnimationName은 비어 있다. 이동과 시각 모션이 불일치할 수 있다. 물 강공격은 별도 돌진 구현이어서 일반 공격의 거리·접근 설정으로는 조정되지 않는다.

## 이번에 반영한 변경

- 일반 소프트 타겟팅: 카메라 시선과 적 콜라이더 중심 사이의 각도 우선. 동일 각도에서는 플레이어와의 거리 우선. 화면 밖과 콘 밖의 후보를 제외한다.
- 기본 콘 반각 60도(`PlayerController.TargetingHalfAngle`). 기존 10m 검색 반경, 높이·사망·장애물 검사는 유지한다. 공격 중에는 타깃을 유지하고 다음 콤보 타수 시작 때 다시 선택한다.
- 걷기 상태를 제거하고 기본 지상 이동 및 행동 종료 후 복귀를 Run으로 통합했다. 공중 수평 이동도 RunSpeed를 사용한다. 달리기 중 폼 전환이 가능하다.
- 스태미나 런타임·소모·회복·데이터 필드를 제거했다. 대시는 기존 쿨타임을 사용한다. 기존 직렬화 스탯 번호는 유지했다.
