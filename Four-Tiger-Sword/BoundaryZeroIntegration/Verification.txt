BoundaryZERO UI 적용 검증 기록
검증일: 2026-10-29 / Unity 6000.3.10f1 / Game Scene / Editor Play Mode

적용 범위
- 실행 중인 PlayerHUD, 구매/판매/합성, 미니맵/전체 지도, 오행 휠, 결과/로딩 프리팹 및 씬 연결.
- PNG 104개를 가져옴. PNG/Items와 메인 메뉴용 이미지는 제외.
- 모든 가져온 PNG의 Sprite/Bilinear/무압축/MipMap 비활성을 Editor API로 확인.
- 프레임의 border/pivot은 제공 manifest를 적용. 큰 창은 화면 내부에 맞추고 HUD는 가장자리에 고정.
- 원래 ItemDefinition 20개의 icon 참조를 적용 전 기록과 비교: 변경 0개.
- 기존 E/R 스킬, 기력, 궁극기 충전, 2개 같은 등급 재료 합성 및 4등급 처리 규칙을 유지.
- 상점 카드는 조회만 수행. 거래 및 재료 추가/제외는 별도 버튼으로 실행.
- 기존 한글 NotoSansKR 원본 서체를 사용하되, 작은 해상도의 글자 테두리 문제를 해결하기 위해 적용 UI 전용 SDF를 48pt/padding 5로 생성. 원래 폰트 에셋은 유지.

플레이 검증
- 실제 프레임 진행 상태에서 F 상점 열기, 카드 조회, 상세 버튼 구매, 휠 스크롤, 회복, Tab 접기/펼치기와 Esc 접기/닫기를 확인.
- 판매, 같은 등급 재료 2개 합성, 소모된 아이템 선택 참조 정리, 골드/소유권 변화 및 기존 아이콘 표시를 확인.
- 필터, 탭별 소지품 스크롤 및 펼침/접힘별 상품 스크롤을 검증. 긴 한글 상세는 스크롤로 표시.
- 체력/기력/속성 표시, E/R 입력, 궁극기 충전 및 실제 R 실행 후 재사용 시간 변화를 확인.
- 미니맵의 실제 지도와 전체 지도 연동을 확인. 전체 지도 방 클릭 후 약 76.7m 빠른 이동, 지도 닫힘 및 현재 방 갱신을 확인.
- 오행 휠의 기존 선택 방향/감도/중앙 취소 영역을 유지하고 선택 표시를 확인.
- 상점/전체 지도는 HUD까지 포함한 직전 화면을 캡처하여 블러 처리. D3D 캡처 방향 보정 후 이미지 확인. 두 창 모두 닫힘 뒤 RawImage texture=null 및 IsShown=false 확인.
- 8개 구역의 실제 진행, 생성 실패 후 재시도, 승리, 사망, 새 탐사 재시작을 검증.
- 재시작 뒤 피해 텍스트 풀에서 발생하던 MissingReference 문제를 수정하고 다시 피해를 주어 예외가 없는 것을 확인.

화면 검증
- 2560×1440: HUD, 구매, 판매, 합성, 합성 결과, 전체 지도, 오행 휠, 성공, 사망, 생성 오류, 로딩.
- 1920×1080 / 1280×720 / 3440×1440: 실제 Game View 해상도별 상점 촬영 및 창 경계 검사. 720p/울트라와이드 HUD도 촬영.
- Comparison.html은 제공된 A 배치 안내와 최종 화면을 나란히 표시.
- 최종 성공/사망/생성 오류/로딩 이미지는 같은 실행 세션에서 해당 표시 함수를 호출하여 촬영한 시각 비교용 화면. 실제 상태 전이와 버튼 연결은 위 플레이 회귀 검사로 별도 확인.
- 촬영용 재화/아이템은 플레이 세션에만 추가했으며 원본 게임 데이터에 저장하지 않음.
- Review의 Shop_Debug, Shop_FontProbe, ShopPointerCurrent, HUD_Resources, HUD_Ultimate는 작업 중 진단 이미지이며 최종 비교 화면이 아님.

마무리 확인
- 최종 재컴파일: completed, failed=false, errors=[]
- 적용 프리팹 8개의 Missing Script: 모두 0
- 최종 플레이 세션 콘솔의 Error 1건은 검증 명령 'editor status' 오타에 대한 Unity Pipeline 오류였음. 게임 코드 예외/경고는 없었음.
- 테스트 재생 종료, 원래 Game View 해상도 복원, 임시 해상도 항목 제거, runInBackground 원래 값 복원.
- 비교 이미지 폴더를 Assets 밖 BoundaryZeroIntegration/Review로 이동.
- 무관한 작업 중 변경사항은 되돌리지 않음. 커밋/스테이징하지 않음.
- 검증은 Windows Editor Play Mode 기준이며 별도 플레이어 빌드는 수행하지 않음.
