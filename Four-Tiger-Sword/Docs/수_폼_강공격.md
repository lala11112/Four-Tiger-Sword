# 수 폼 게이지와 강공격

- 게이지는 3칸이며 한 칸이 완성되면 강공격 1회를 사용할 수 있습니다.
- 현재 임시 수치: 한 칸 100, 평타 적중당 12, 스킬 사용당 100. 최대 300입니다.
- 평타는 실제 적중한 대상·타격 판정마다 충전됩니다. 스킬은 적중 여부와 무관하게 사용 시 한 번 충전됩니다.
- 강공격·공중 공격·반격·궁극기는 이 게이지를 충전하지 않습니다.
- 폼을 전환해도 게이지와 미완성 칸의 충전량을 유지합니다. 기존 만충 시 공속·이속 버프는 제거했습니다.

## 조작

- 게이지가 한 칸 이상 있으면: 공격 버튼을 짧게 눌렀다 떼면 평타, 0.35초 유지하면 강공격.
- 평타 중 추가 공격 입력을 길게 누르면 해당 타수의 `ComboTransitionTime` 이후 강공격으로 파생됩니다. 마지막 타수에서도 가능합니다.
- 유지 시간이 충족된 입력은 버튼을 떼더라도 연결 가능 시점까지 유지됩니다.
- 대기/이동/달리기에서도 같은 길게 누르기로 평타 없이 강공격을 시작할 수 있습니다.
- 한 번 계속 누르고 있는 입력으로 여러 칸을 연속 소모하지 않습니다. 다음 공격은 새 입력이 필요합니다.
- 강공격 대시 중 공격 버튼을 다시 누르면 다음 강공격을 예약합니다. 게이지가 남아 있으면 현재 대시 종료 즉시 다음 대시로 연결되며, 추가 충전 시간이나 Idle 전환은 없습니다. 종료 프레임의 새 입력도 연결됩니다.
- 이동 방향 입력이 있으면 그 방향으로, 없으면 플레이어가 바라보는 방향으로 대시합니다. 대시 중 방향은 고정되고 다음 대시 시작 시 새 방향을 받습니다.
- 대시 중 적은 관통하지만 벽은 관통하지 않습니다. 적의 공격에 대한 무적 효과는 없습니다. 종료·취소·사망 시 충돌 설정을 복구합니다.
- 게이지가 부족하면 버튼을 누르는 즉시 기존 평타가 나갑니다. 다른 속성 폼도 기존 입력 방식을 유지합니다.
- 강공격 시작 시 한 칸을 소모합니다. 시작 전 피격·회피·점프·패링으로 취소하면 소모하지 않으며, 시작 후 취소하면 환불하지 않습니다.

## 조정 위치

`Assets/_Project/Scripts/FormActions/WaterFromAction.asset` Inspector:

- `Heavy Attack Step`: 모션, 피해량, 강인도 피해, 대시 시간(`Duration`), 타격 시작/지속 시간, 판정 반경(`HitBoxRadius`)·위치(`HitBoxOffset`), 이펙트.
- `Water Heavy Dash Distance`: 대시 거리. 기본 6m, 시간은 기본 0.35초이며 공격 속도의 영향을 받습니다. 총 대시 거리는 공격 속도와 무관합니다.
- `Heavy Attack Hold Time`: 길게 누르기 판정 시간. 공격 속도와 무관한 게임 시간입니다.
- `Water Gauge Per Segment`, `Water Normal Hit Gain`, `Water Skill Use Gain`: 게이지 수치.

## 수 속성 스킬: 전방 공격 + 플레이어 버프

스킬 사용 시 플레이어가 바라보는 방향으로 공격하며, 게이지와 버프를 즉시 얻습니다.
기존 돌진 모션·이동 커브를 활용하고 타격 범위를 전방에 배치했습니다.
자동으로 뒤쪽 적을 향해 회전하지 않으며, 기존 스킬의 추가 지연 타격은 제거했습니다.

같은 `WaterFromAction.asset` Inspector에서 조정합니다.

| 항목 | 기본값 | 의미 |
|---|---:|---|
| `Water Skill Use Gain` | 100 | 스킬 사용당 게이지 획득량. 평타 적중당 12보다 큼 |
| `Water Skill Buff Duration` | 6 | 버프 지속 시간(게임 시간, 초) |
| `Water Skill Attack Bonus Percent` | 20 | 플레이어 공격력 +20%. 기존 공격력 증가율과 합산 |
| `Water Skill Heavy Damage Bonus Percent` | 30 | 수 폼 강공격 피해에 추가로 ×1.3 |
| `Skill Steps` | 기존 데이터 | 전방 공격의 모션·피해·범위·타격 시점·이동 커브 |

버프는 스킬을 빗맞혀도 부여됩니다. 스킬 모션 종료·피격·폼 전환으로 사라지지 않고,
재사용하면 중첩 없이 수치와 지속 시간을 갱신합니다. 지속 시간 0은 버프 비활성화입니다.
폼 전환 후에도 플레이어 공격력 버프는 유지되며, 추가 강공격 피해는 수 폼 강공격에만 적용됩니다.
만료·사망·플레이어 비활성화 시 해당 버프의 증가분만 제거합니다.

다른 공격력 증가 효과가 없으면 기본값에서 일반 공격은 ×1.2,
수 폼 강공격은 ×1.2 ×1.3 = ×1.56의 피해를 줍니다. 강인도 피해에는 추가 30%가 적용되지 않습니다.
활성화 중 Inspector 수치를 바꾸면 다음 스킬 사용부터 새 버프 수치가 적용됩니다.

UI가 필요하면 `WaterForm.IsSkillBuffActive`, `SkillBuffRemaining`,
`SkillAttackBonusPercent`, `HeavyAttackDamageMultiplier`를 읽을 수 있습니다.
버프 UI는 구현하지 않습니다.

강공격은 현재 `WaterSkill` 돌진 모션을 재사용하는 대시 공격입니다. 기본 피해 계수 2.4, 강인도 피해 40이며 이동 경로를 쓸어 검사해 한 대시당 각 적에게 한 번 피해를 줍니다. 다음 대시는 같은 적을 다시 타격할 수 있습니다.
수 폼 대시 강공격은 `HitEvents`, `ThrustCurve`, `UseTargetApproach` 대신 단일 타격 구간과 `WaterHeavyDashDistance`를 사용합니다. 전용 충전 모션은 없으며, 직접 강공격을 준비하는 동안은 Idle을 사용합니다.

## UI 담당자용 수치 접근

게이지 UI 오브젝트와 생성·갱신 코드는 제거했습니다. 전투 로직은 수치만 관리합니다.
플레이어 초기화가 끝난 후 `PlayerController.FormManager.CurrentForm`을 `WaterForm`으로 확인하여 읽습니다.

```csharp
if (player.FormManager?.CurrentForm is WaterForm water)
{
    float current = water.WaterGauge;                 // 현재량: 기본 0~300
    float maximum = water.WaterGaugeMax;              // 최대량: 기본 300
    float perSegment = water.WaterGaugePerSegment;    // 한 칸: 기본 100
    float ratio = water.WaterGaugeRatio;              // 전체 비율: 0~1
    int segmentCount = water.WaterGaugeSegmentCount;  // 전체 칸 수: 3
    int charges = water.HeavyAttackCharges;           // 완성된 칸 수: 0~3
}
```

모든 값은 읽기 전용입니다. `i`번째 칸(0~2)의 비율은
`Mathf.Clamp01(water.WaterGauge / water.WaterGaugePerSegment - i)`로 계산할 수 있습니다.
게이지 수치 변경 이벤트는 없으므로 UI 갱신 시 위 프로퍼티를 읽으면 됩니다.
폼 변경 알림은 기존 `player.FormManager.OnFormChanged` 이벤트로 받을 수 있으며,
현재 폼이 수 폼이 아닐 때 표시 여부는 UI 측에서 결정합니다.
수 폼이 아닌 동안에도 수치가 필요하면 전달받은 `WaterForm` 인스턴스를 보관하여 읽을 수 있습니다.
