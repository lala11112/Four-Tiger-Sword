# 토속성 스킬·궁극기

설정: `Assets/_Project/Scripts/FormActions/EarthFormAction.asset` (`EarthFormActionDataSO`).
일반 공격과 첫 타 가드/반격은 유지합니다. 기존 궁극기의 피해 흡수 후 폭발은 제거했습니다.

## Inspector 설정

| 항목 | 기본값 | 의미 |
|---|---:|---|
| Skill Spirit Cost | 150 | 스킬 영력 비용 |
| Skill Cooldown Seconds | 8 | 스킬 종료 후 쿨타임(초) |
| Skill Dash Distance | 5 | 전방 돌진 거리(m) |
| Skill Dash Duration | 0.4 | 돌진 시간(초), 공격 속도와 무관 |
| Skill Dash Damage Multiplier | 2 | 공격력에 곱하는 돌진 피해 계수 |
| Skill Dash Hit Radius / Offset | 1.2 / (0, 1, 0.8) | 이동 경로의 타격 반경 / 중심 위치 |
| Shield Amount / Duration | 300 / 5 | 스킬 방어막 양 / 지속 시간(초) |
| Ultimate Shield Amount / Duration | 600 / 10 | 궁극기 방어막 양 / 지속 시간(초) |
| Ultimate Buff Duration | 10 | 궁극기의 조건부 피해 증가 버프 시간(초) |
| Ultimate Shield Damage Bonus Percent | 30 | 방어막이 남아 있을 때 주는 피해 증가율(%) |

스킬은 사용 즉시 방어막을 부여하고 바라보는 방향으로 돌진합니다. 적과 벽의 충돌은 유지합니다.
이동한 경로를 검사하여 각 적을 스킬당 한 번 타격합니다. 스킬 중단 시 이동과 타격도 멈춥니다.
`Skill Steps[0]`에서 애니메이션, 전체 동작 시간, 넉백, 경직 및 이펙트를 설정합니다.
돌진 거리·피해·판정은 위 전용 필드를 사용하며 기존 Hit Events/Thrust Curve는 사용하지 않습니다.
전체 동작은 첫 스텝 Duration과 돌진 시간 중 긴 값까지 유지됩니다. 현재 에셋의 애니메이션 이름은 비어 있습니다.

궁극기는 가득 찬 게이지를 소모하고 공통 `Ultimate Cooldown`을 시작합니다.
즉시 방어막과 버프를 얻고 일반 조작으로 돌아갑니다. `Ultimate Steps`는 사용하지 않습니다.
버프 시간 중 두 토속성 방어막 중 하나라도 남아 있으면 피해가 증가합니다.
모두 파괴되면 증가 효과가 멈추며, 버프가 끝나기 전에 스킬 방어막을 다시 얻으면 다시 적용됩니다.
궁극기 버프 시간과 방어막 지속 시간은 독립적입니다.

두 방어막은 합쳐서 하나로 덮어쓰지 않습니다. 먼저 얻은 방어막부터 소모하며 초과 피해는 다음 방어막과 체력으로 넘어갑니다.
동일 출처의 방어막 재사용은 해당 양과 시간만 새로 설정합니다.
폼 전환 시 궁극기 피해 버프는 종료되지만 남은 방어막은 각 지속 시간까지 유지합니다.
사망·플레이어 비활성화 시 토속성 방어막과 버프를 정리합니다.

## UI 연결

UI는 추가하지 않습니다. `EarthForm.SkillShield`, `UltimateShield`와 각각의 `...Remaining`으로 양과 시간을 읽습니다.
`UltimateBuffRemaining`, `IsUltimateDamageBuffActive`, `OutgoingDamageMultiplier`로 궁극기 상태를 읽습니다.
전체 방어막 합계는 기존 `PlayerStatManager.Shield`입니다.
공통 스탯 매니저에는 출처별 방어막 저장/소모 기능만 두고, 토속성의 수치와 발동 규칙은 전용 SO/폼에 둡니다.

## 검증

`Tools/WaterCombatRegression.cs`에서 독립 방어막, 재사용, 만료, 피해 분배, 조건부 피해 증가,
돌진 거리, 중복 타격 방지, 중단 및 폼 전환을 검증합니다.
