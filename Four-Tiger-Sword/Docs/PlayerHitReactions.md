# 플레이어 피격 반응

`PlayerController`의 **Hit Reaction Settings**에서 모션 이름과 시간을 설정합니다.

| 상태 | 기본 진입 조건 | 기본 행동 제한 시간 |
| --- | --- | --- |
| PlayerHitState | 피해 적용, 경직 기준 미만, 유효 넉백 없음 | 0.15초 |
| PlayerStaggerState | 1회 poiseDamage가 20 이상, 유효 넉백 없음 | 0.4초 |
| PlayerKnockbackState | 힘이 기존 넉백 저항을 초과하고 수평 방향이 있음 | 경직 시간과 넉백 시간 중 긴 값 |

- `StaggerPoiseThreshold`는 1회 타격 기준이며 누적 강인도 게이지가 아닙니다.
- `HitStaggerResistance`와 같거나 낮은 공격 등급은 반응을 발생시키지 않습니다. SUPER_ARMOR는 다운을 포함한 모든 피격 반응을 막지만 체력 피해는 받습니다.
- 보호막으로 흡수한 타격도 반응합니다. 피해량이 0인 타격, 회피, 폼의 방어/무적, 성공한 패링은 피격 상태에 들어가지 않습니다.
- 기본 애니메이션 상태 이름은 `Hit`, `Stagger`, `Knockback`입니다. 전용 상태가 없으면 `Hit`, 그마저 없으면 `Idle`로 폴백합니다. Animator에 모션을 연결해야 실제 피격 동작이 보입니다.
- 진입 시 이전 공격/스킬/공중 공격의 Exit를 실행합니다. 피격 중 행동 입력을 소비하고 이동 입력은 적용하지 않으며 중력은 유지합니다.
- 동일 강도의 연속 피격은 시간을 갱신합니다. 약한 피격이 진행 중인 강한 반응을 취소하지 않습니다. 사망은 모든 피격 반응보다 우선합니다.
- 회복 후 공중이면 낙하, 지상이면 입력에 따라 대기/이동/달리기로 복귀합니다.
- 일반 피격 넉백은 상태에서 선형 감속 이동합니다. 패링 성공 시 밀림은 기존 코루틴으로 처리해 반격 기회를 유지합니다.

## 스킬 슈퍼아머와 다운 중단

- 일반 스킬(E), 연계 스킬(F), 필살기(R)는 각각 `PlayerSkillState`, `PlayerSwitchAttackState`, `PlayerUltimateState`가 실행되는 동안 일반 피격·경직·밀림으로 중단되지 않습니다. 시전 시작부터 후딜까지 보호하며, 체력·보호막 피해와 피격 카메라 효과는 유지합니다.
- 적 공격의 명시적인 다운 설정과 기존 경직 저항 판정을 통과한 타격은 스킬을 중단하고 `PlayerKnockdownState`로 전환합니다. 공격의 경직 등급이나 넉백 힘이 높다는 이유만으로 다운 공격이 되지는 않습니다.
- 중단 시 기존 스킬 `Exit`가 실행되어 충돌 설정·애니메이션 속도·카메라를 정리합니다. 쿨타임·자원 소비·이미 적용된 지속 효과는 각 폼의 기존 종료 규칙을 따릅니다. 사망은 스킬 슈퍼아머보다 우선합니다.
- 현재 상태로 보호 여부를 판단하므로 `HitStaggerResistance`는 변경하지 않습니다. 스킬 종료·취소 후에는 보호가 남지 않으며, 지속 버프만 남은 시간에는 적용하지 않습니다. 일반 공격·강공격·반격에는 이 보호를 부여하지 않습니다.
- 수 폼 필살기 등의 기존 무적·방어는 그대로 유지되어 무적 중 다운도 막습니다. 수 폼 필살기의 무적이 종료된 후딜에는 일반 피격 보호만 남고, 유효한 다운 공격은 중단시킬 수 있습니다.

## 달리기 중 행동

Run → Attack을 유지하고 Run → Skill / Ultimate를 추가했습니다. 스킬의 쿨타임·데이터 조건과 궁극기의 게이지·쿨타임·데이터 조건을 그대로 사용합니다.

## 검증

`PlayerHitReactionRegression.Run()`에서 E/F/R 실행 중 일반 타격·높은 경직·보호막으로 흡수한 넉백의 비중단, 다운 전환과 종료·자원 처리, 같은 프레임 다운 우선순위, 스킬 종료 후 피격 복귀, 일반·강공격 중단, 수 폼 필살기의 무적과 후딜, 스킬 중 사망을 검증합니다. Unity 컴파일과 피격 254개·스킬 이동 77개·폼 연계 53개·행동 타이밍 148개 검증 항목을 통과했습니다.

Unity 재컴파일 및 임시 객체를 사용하는 Editor 검증으로 공격 중단, 입력 버퍼 소비, 연속 경직 갱신, 넉백 우선순위/거리, 슈퍼아머, 공중 공격 정리, 낙하 복귀, 패링 반격 유지, 달리기 행동 조건, 사망 우선순위를 확인했습니다. 실제 모션과 조작감은 Play Mode에서 조정해야 합니다.
