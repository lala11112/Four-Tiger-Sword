# 사인검 아이템 검토용 초안

콘텐츠 상태: draft. revision 71.

JSON/PNG는 새 Unity 폴더에 복사하여 TextAsset/Texture로 반입할 수 있습니다. PNG는 Sprite (2D and UI), Single로 설정하세요. 기존 Assets를 덮어쓰지 마세요.

아이템 런타임 적용은 미연결입니다. 이 패키지는 ItemDefinition/SO/Importer/전투효과 실행기를 포함하지 않습니다. JSON의 metal은 문자열이며 기존 enum 정수가 아닙니다. 비율 0.08은 8%입니다.

개별 효과·수치·정책·아트는 제안입니다. 생성과 파일 검증은 사용자 채택을 대신하지 않습니다. 초안 묶음에는 미채택 정책이나 누락 아이콘이 있을 수 있으며 validation-report.json을 함께 확인하세요.
