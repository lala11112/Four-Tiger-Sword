배관 · 전기선 Unity 패키지 v3

URP 프로젝트: Pipe_Cable_Kit_v3_URP.unitypackage
Built-in 프로젝트: Pipe_Cable_Kit_v3_BuiltIn.unitypackage
프로젝트 렌더 파이프라인에 맞는 하나만 가져오세요.

1. Unity의 Assets > Import Package > Custom Package에서 선택 후 Import.
2. Assets/PipeCableKit/Prefabs에서 필요한 프리팹을 씬으로 드래그.
3. 전체 예제: Assets/PipeCableKit/Scenes/PipeCable_Demo.unity

모델 16종: 배관 4두께 + 전기선 4두께, 각 직선과 ㄱ자.
외경: 배관 52/78/130/195mm, 전기선 16/26/42/65mm.
직선 길이는 1m. ㄱ자는 중심선 기준 각 방향 1m이며 둥근 모서리입니다.
피벗과 Start는 시작 끝점 (0,0,0), End는 직선 (1,0,0), ㄱ자 (1,1,0).
끝단 링이나 색 띠가 없고, 배관은 속이 열려 있습니다.
최신 두께 확대 및 청회색 도장 금속/무광 고무 텍스처가 적용되어 있습니다.

머티리얼·프리팹은 이미 생성되어 있어 별도 메뉴 실행이 필요하지 않습니다.
렌더 파이프라인을 바꿨을 때 Tools > Pipe Cable Kit > Build Prefabs로 재생성할 수 있습니다.
이 메뉴는 해당 키트의 생성 머티리얼과 프리팹을 덮어씁니다.
LOD 및 콜라이더는 포함하지 않습니다. 필요 시 별도 추가하세요.
ProjectSettings 또는 다른 프로젝트의 에셋은 패키지에 포함하지 않습니다.

제작 및 임포트 검증: Unity 6000.3.21f1. URP 검증 버전 17.3.0.
