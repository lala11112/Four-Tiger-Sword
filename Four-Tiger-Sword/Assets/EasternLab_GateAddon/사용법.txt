연구실 워프게이트 설치
기존 동양 사이버 연구실 URP 모델링 패키지와 함께 사용합니다.

1. 씬의 EasternLab_Model 바로 아래에 WarpGate_Addon 프리팹을 넣습니다.
   애드온의 로컬 위치와 회전은 (0, 0, 0), 스케일은 (1, 1, 1)로 둡니다.
2. WarpGate_Addon의 Gate Addon Settings에서 목적지를 정합니다.
   다른 씬으로 이동하려면 ‘목적지 씬’에 실제 씬 이름을 입력하고 그 씬을 활성 Build Profile의 Scene List에 등록합니다.
   같은 씬에서 이동하려면 ‘목적지 씬’을 비우고 ‘같은 씬의 도착 지점’에 빈 오브젝트를 끌어 놓습니다. 도착 지점의 위치와 회전이 플레이어의 도착 위치와 방향입니다.
3. 기존 플레이어에 CharacterController 또는 Rigidbody와 Collider가 있어야 합니다.
   MainCamera 태그를 쓴 카메라는 자동 연결됩니다. 외부 카메라나 별도 플레이어 구조를 사용하면 ‘플레이어 카메라’와 ‘플레이어 (선택)’를 직접 지정하세요.
4. 재생 후 게이트 오른쪽 패널을 3m 이내에서 바라보고 E를 누릅니다. 개방이 끝나면 게이트 중앙으로 걸어갑니다. 열린 상태에서 오른쪽 패널을 다시 조작하면 닫힙니다.
   유효한 목적지 없이도 개방 연출을 볼 수 있습니다. 실제 이동은 목적지를 연결한 뒤 사용할 수 있습니다.

기존 상호작용 버튼을 쓰려면 RightGatePanel의 Use Built In Input을 끄고 같은 컴포넌트의 Operate()를 호출합니다. 카메라가 해당 패널을 바라보고 있어야 합니다.
모델에 빠진 충돌체 추가 옵션은 연구실의 바닥·벽·문틀에 물리 충돌체를 실행 중 추가합니다. 별도 충돌 구조를 이미 제작한 경우 끌 수 있습니다.
다른 씬으로 넘어간 뒤 플레이어 생성과 시작 위치는 도착 씬의 기존 설정을 따릅니다.
