직선 · ㄱ자 배관 및 전기선 — 2배 두께 버전

구성: 직선 배관 4종, ㄱ자 배관 4종, 직선 전기선 4종, ㄱ자 전기선 4종 — 총 16종
기존 v3 모델의 지름을 정확히 2배로 키웠습니다. 이미 별도로 제공한 T자는 포함하지 않습니다.

규격
- 배관 외경: 104 / 156 / 260 / 390 mm
- 전기선 외경: 32 / 52 / 84 / 130 mm
- 직선 길이: 1m
- ㄱ자 끝점 중심 간 가로·세로 거리: 각각 1m
- ㄱ자 곡선의 중심선과 굽힘 반경은 기존과 같습니다.
- 프리팹 루트 Scale은 (1,1,1)이며 메시의 단면을 두껍게 만들었습니다.
- 기존 청회색 금속·무광 고무 재질과 PBR 텍스처, 돌출 이음새 없는 끝단을 유지했습니다.

설치
프로젝트에 맞는 패키지 하나를 Assets > Import Package > Custom Package로 불러오세요.
- URP: Pipe_Cable_Kit_2x_URP.unitypackage
- Built-in: Pipe_Cable_Kit_2x_BuiltIn.unitypackage

프리팹: Assets/PipeCableKit2x/Prefabs
예제 씬: Assets/PipeCableKit2x/Scenes/PipeCable_Demo.unity

별도 PipeCableKit2x 폴더에 설치됩니다. 기존 씬에는 새 프리팹을 배치하세요.
Start / End 자식 오브젝트를 연결 기준점으로 사용할 수 있습니다.
배관 내부는 비어 있습니다. 충돌체와 LOD는 포함하지 않습니다.
2배 두께 T자 패키지(PipeCableTeeKit2x)와 같은 지름 규격입니다.
