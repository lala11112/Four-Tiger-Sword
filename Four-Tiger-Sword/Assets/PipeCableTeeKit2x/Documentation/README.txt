T자 배관 · 전기선 2배 두께 버전

기존 T자 8종의 지름을 정확히 2배로 키운 버전입니다.
중심 접합점에서 좌·우·위 끝점까지 각각 1m, 좌우 전체 길이 2m는 유지했습니다.
프리팹 루트 Scale은 (1, 1, 1)이며, 메시 자체의 지름을 변경했습니다.

외경
- 배관: 104 / 156 / 260 / 390 mm
- 전기선: 32 / 52 / 84 / 130 mm

사용 방법
프로젝트 렌더 파이프라인에 맞는 패키지 하나를 임포트하세요.
- URP: Pipe_Cable_Tee_2x_URP.unitypackage
- Built-in: Pipe_Cable_Tee_2x_BuiltIn.unitypackage

Unity > Assets > Import Package > Custom Package에서 선택합니다.
프리팹: Assets/PipeCableTeeKit2x/Prefabs
예제 씬: Assets/PipeCableTeeKit2x/Scenes/PipeCableTee_Demo.unity

별도 PipeCableTeeKit2x 폴더에 설치됩니다. 기존 씬에는 새 프리팹을 배치하세요.
이 패키지는 T자 8종만 포함합니다. 기존 청회색 금속·무광 고무 재질과 텍스처를 유지했습니다.
배관 내부는 세 방향으로 통하고 끝단 돌출 이음새는 없습니다.
Left / Right / Top 자식 오브젝트는 연결 기준점입니다. 충돌체와 LOD는 포함하지 않습니다.
