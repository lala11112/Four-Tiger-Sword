BAEKHO MAP — Unity 가져오기

1. ZIP 파일의 압축을 풉니다.
2. Baekho에서 프리팹을 스캔한 것과 동일한 Unity 프로젝트를 엽니다. GUID로 원본 프리팹을 찾으므로 해당 .meta 파일을 유지해 주세요.
3. Unity/Editor/BaekhoMapImporter.cs를 프로젝트의 Assets/Baekho/Editor/BaekhoMapImporter.cs로 복사합니다. 이미 설치했다면 같은 파일을 업데이트하고 다른 폴더에 중복 복사하지 마세요.
4. Map.baekhomap.json을 Assets 안의 원하는 폴더로 복사합니다.
5. Unity의 컴파일이 끝나면 Project 창에서 Map.baekhomap.json을 선택하고 Assets > Baekho > Build Prefab 메뉴를 실행합니다.
6. JSON 파일과 같은 폴더에 맵 이름의 .prefab이 자동으로 생성되고 선택됩니다. 같은 이름이 있으면 번호가 붙은 새 파일을 만들며 기존 프리팹을 덮어쓰지 않습니다.

ZIP에는 배치 데이터와 가져오기 스크립트가 포함됩니다. 원본 프리팹 사본은 포함되지 않습니다.
좌표 단위는 미터이며 Y가 위쪽, X/Z가 격자 평면입니다. 맵의 중심은 원점입니다.
입구와 출구는 이름이 지정된 빈 GameObject로 생성됩니다. 게임의 스폰·출구 로직에 연결해 주세요.
콜라이더, 내비게이션 베이크, 게임 로직, 조명과 에셋 크기 조정은 Unity 프로젝트에서 구성해 주세요.

blueprint.png는 참고용 AI 설계도 원본입니다.

높이·계단 설정
- 각 셀의 높이는 미터 단위이며 프리팹의 Y 배치에 반영됩니다. 같은 X/Z 셀에 여러 층이 겹치는 구조는 지원하지 않습니다.
- R 타일의 높이는 계단 저단입니다. 상승 화살표 방향으로 이웃한 칸이 고단이며 rise만큼 올라갑니다. 방향 0도는 +Z(북쪽), 90도는 +X(동쪽), 180도는 -Z(남쪽), 270도는 -X(서쪽)입니다.
- 계단 원본은 저단 높이 0에서 -Z 쪽으로 진입하여 +Z 쪽 고단으로 올라가도록 준비합니다. Y 스케일 1일 때 실측한 원본 상승 높이를 Baekho의 stairNativeRise에 입력해 주세요. 내보내는 계단 Y 스케일은 rise / stairNativeRise로 자동 계산하여 각 계단의 목표 상승 높이에 맞춥니다. 예전 계단 연결에 값이 없으면 원본 상승 높이를 1m로 가정합니다.
- 계단의 X/Z 스케일은 사용자가 설정한 값을 유지합니다. 원본 에셋의 폭·깊이가 셀 크기(cellSize)에 맞도록 X/Z 스케일과 offset을 조정해 주세요.
- 내보낸 계단 회전은 상승 화살표 방향 + 사용자 rotationY입니다. 계단의 실제 충돌체와 이동 가능 여부가 설계도의 저단·고단 연결과 맞는지 Unity에서 확인해 주세요.
- maxStepHeight는 Baekho의 경로 검증 기준입니다. 게임 캐릭터 컨트롤러의 단차·경사 설정과 NavMesh 설정도 이에 맞춰 주세요.
