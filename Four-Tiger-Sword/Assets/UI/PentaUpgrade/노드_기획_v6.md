# 노드 기획 v6 — 의미 있는 성장 선택 확장

> **내용 미확정:** 아래 이름·효과·선행 관계는 화면 비교에 쓰는 후보 초안이다. v7에서 선택된 것은 2안 세로 줄기형 배치와 탐색 방향뿐이며, 노드 상세 기획의 승인을 뜻하지 않는다. 이 문서의 가로 배치 설명은 이전 v6 기록이며 현재 v7의 화면 배치에는 적용하지 않는다.

무료 시작점과 구매 성장 개념을 포함한 역할·연결 정리다. 기존 성장 개념과 선행 조건·설명을 유지하면서 공격 방식, 위치 선정, 전투 후 정비, 보상 후보와 조합 선택의 폭을 확장했다. 게임플레이 수치·가격·레벨은 확정하지 않는다. 전투·경제 동작이나 실제 해금 상태를 구현한 작업은 아니다. 시작점은 이미 열린 무료 기준점이며 구매 대상이 아니다.

별도 카테고리 벽이나 능력치만 있는 트리로 만들지 않는다. 각 효과는 기존 행동에 반응하는 패시브 또는 기존 보상·합성 선택의 개선이다. 전투 중 추가 조작 버튼이나 새로운 전투 시스템을 요구하지 않으며 스태미나·폼 전환을 다루지 않는다.

## 연결 원칙

모든 구매 노드는 선행 노드를 하나만 가진다. 깊이는 선행 노드 다음 단계이며, 같은 깊이에서는 부모의 가로 순서대로 자식을 묶는다. 기존 자식의 상대 순서를 유지한 뒤 새 자식을 붙인다. 인접 깊이 사이의 선이 교차하지 않는 구조다. 기존 성장 노드의 선행 조건은 바꾸지 않는다.

## 기존 통합과 보류 개념

기존 통합·보류 방향은 유지한다. 다만 `escape`와 `combo`는 아래처럼 조건이 분명한 새 효과로 복귀한다. 이동 제안은 해당 콘텐츠가 구현되었다는 의미가 아니다.

## 구현 전 확정할 제한

- 부활 기회는 같은 런에서 회복·상점 방문으로 다시 충전되지 않는다. 무적과 밀쳐내기를 부활에 포함한다. 필수적인 기본 회피 무적과 조작 기능을 노드 구매 뒤에 가두지 않는다.
- 회피 반격은 실제 적 공격의 회피 성공으로 준비되고 다음 공격에 소비한다. 중복 축적하지 않는다. 빈 회피 동작으로 충전하지 않도록 성공 판정을 정의한다.
- 예리한 감각은 직접 공격 적중만 대상으로 한다. 지속 피해·반사·발동형 추가 피해의 재귀 누적을 막고 다중 적중·광역 공격 판정 단위를 확정한다.
- 집중 공격은 같은 대상의 연속 직접 공격에서만 성장한다. 대상 변경·공격 중단 시 초기화하며 추가 타격을 만들지 않는다. 선제 타격도 최대 체력 대상에 대한 첫 직접 공격만 판정한다.
- 검격 범위는 근접 기본 공격의 도달 범위만 늘린다. 투사체와 다른 공격의 범위는 바꾸지 않는다. 공격 속도와 처치의 기세는 회피 무적 시간이나 안전 판정을 바꾸지 않도록 공격 동작과 분리한다.
- 치명적 회수는 직접 공격의 치명타 처치마다 중복 없이 발동하는 직접 회복이다. 보호막 획득을 회복으로 간주해 재발동하지 않는다. 소환·반복 재생성 적을 이용한 회복 파밍을 막는다.
- 전투 후 정비는 실제 전투 방의 첫 클리어에만 적용한다. 재입장·빈 방 통과로 반복 회복하지 않는다. 최대 체력 변경이나 재분배로 공짜 회복을 얻지 않도록 현재 체력 처리 규칙을 정한다.
- 온전한 수호는 실제로 넘친 회복량을 기준으로 삼는다. 유지·갱신·누적 제한을 정해 안전한 장소에서 무한히 보호막을 쌓지 못하게 한다. 치명적 회수와 함께 쓸 때도 이 제한을 지킨다.
- 공격·치명타·선제 타격·집중 공격·마무리 일격·배후 공략의 합산·곱연산과 상한은 이후 검증한다. 피해 경감·위기 방어·포위 대응·결전 대비의 중첩도 함께 검증한다. 체력·회복·보호막·부활을 합친 생존력도 묶어서 본다.
- 결전 대비는 보스전 시작에 준비되고 첫 피격에 소비한다. 종료·재진입으로 반복 준비되지 않도록 보스전 경계를 정한다. 포위 대응의 주변 판정과 위기 탈출의 재발동 방식은 추후 확정한다.
- 경제 효과는 런 안의 골드에만 영향을 주며 영구 성장 재화를 늘리지 않는다. 할인 구매·매각·환불·재구매로 돈이 생기는 순환을 허용하지 않는다. 기본 판매와 상품 새로고침은 원래 가능한 행동이다.
- 출격 유품의 후보 수와 가치 범위는 추후 정한다. 유품의 계통은 초기 후보 풀만 고른다. 선택한 풀에 유효한 미보유 후보가 부족할 때의 대체 규칙을 마련하고 아이템을 복제하지 않는다.
- 넓어진 선택은 일반 전투 보상의 후보만 늘리며 실제 수령은 선택한 아이템만이다. 보상 후보는 기본적으로 확인할 수 있다. 조합의 실마리는 유효한 미보유 아이템의 등장 가중치를 조정하며 완성을 보장하지 않는다.
- 후보 보관은 재선택 때 보관한 후보를 유지하고 나머지만 다시 뽑는다. 보관·재선택·합성 선별로 동일 아이템을 중복 지급하지 않는다. 재선택 기회의 공급과 보관 적용 범위는 추후 확정한다.
- 합성 선별은 기존 합성 재료와 비용을 그대로 사용하고 결과 후보에서 선택한 아이템만 지급한다. 추가 아이템·재료 반환·비용 감소 효과가 아니다. 유효 결과 후보가 부족할 때의 대체 규칙을 정한다.
- 추가 진열은 서로 다른 판매 상품 후보를 늘린다. 구매한 상품을 다시 채우거나 무료 아이템을 지급하지 않는다. 기존 상품 풀과 유효 후보 부족 시 처리 규칙을 정한다.

현재 결과는 역할과 연결이 명확한 개념 카탈로그다. 후보 선택 기능은 기존 보상·합성 흐름에 적용하는 설계안이며 동작이 구현되었다는 뜻이 아니다. 실제 구현에서는 공격·회복·아이템 지급의 발동 경계를 먼저 정한 뒤 수치 밸런스를 조정해야 한다.
